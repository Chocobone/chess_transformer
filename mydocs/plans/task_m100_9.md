**A9′ 절차**

1. **검증 관문**: val의 실제 기보(어댑터 학습에 쓰지 않은 것)로 세 기사 3지선다를 낸다. 정답률의 95% 구간 하한이 1/3을 넘어야 통과한다. 실패하면 A9′는 판정 보류로 두고, 관문 결과도 보고한다.
2. **본 평가**: 어댑터 기보, 베이스 기보, 실제 기보를 섞어 판별한다. 지표는 "해당 기사로 판별된 비율 − 베이스 기보가 같은 기사로 판별된 비율"이다. 기보는 C1·C2 대국 기보를 재사용하며 대국을 추가하지 않는다.
3. **위험 대응**
   - 기보 암기: 헤더(선수·대회·연도)를 지운다. 대국이나 상대를 알아내는지 사전에 확인하고, 알아낸 기보는 뺀다. 유명 대국은 쓰지 않는다
   - 고정관념 채점: 특성 층 결과와의 상관을 함께 보고하고, B12(학습형 식별기)와 비교한다
   - 상대 단서: 평가 대상 쪽의 수만 표시하거나, 국면별 수 선택 형식을 함께 쓴다
   - 국면 추적: 수마다 FEN을 함께 준다. 엔진 도구는 주지 않는 것을 기본으로 한다
4. **재현성**: 여러 번 또는 여러 모델로 독립 실행해 평가자 간 일치도(κ)를 보고한다. 모델 ID, 프롬프트, 응답 원문을 저장한다
5. **고정**: 프롬프트, 모델, 표본 수, 통과 기준을 α > 0 결과를 보기 전에 기준 문서에 고정한다
6. **명칭**: 제안서 6.2와 초록의 "인간 블라인드 평가"와 다르다. "AI 평가자 블라인드 판별"로 따로 보고하고, 제안서와 다른 점으로 적는다

필수로 두지 않는 이유: 관문을 통과해도 고정관념 채점 위험은 남는다. 필수 판정은 정의가 분명한 지표(B10, B6 등)가 맡는다.

카르포프가 필수이므로 B3·B10·B6은 3×3으로 판정한다. 제안서가 가장 어려운 쌍으로 본 스미슬로프-카르포프(둘 다 포지셔널)는 쌍별로 따로 판정한다. 카르포프의 방향 주장("견고·질식", 지문에서 탈과 스미슬로프 사이)은 제안서 특성 4성분에 대응하는 성분이 없다. 따라서 2단계에서 판정 수단(B4 지문 순서 또는 추가 성분 요구)을 정한다.

두 층의 판정은 따로 보고한다. 특성 구현이 늦어져도 특성 없는 층의 판정은 먼저 낼 수 있다. B10은 지금 어댑터로 잴 수 있어 α = 0 기준선을 먼저 확보한다.

### 주장 C: 기력

| # | 수단 | 방법 | 필요 | 한계 | 역할 |
|---|---|---|---|---|---|
| C1 | 베이스와 직접 대국 | 어댑터 대 베이스 136M을 고정 오프닝에서 색을 바꾸어 짝으로 둔다. Elo 차이와 95% 구간을 짝 단위로 집계한다 | 대국 | 자가 대국 성격이라 차이가 과장되거나 줄 수 있다. 무승부 편향이 있다 | **필수 후보** |
| C2 | 외부 고정 상대 대국 | 세 어댑터와 베이스가 같은 강도 제한 Stockfish와 둔다. 같은 척도에서 비교한다 | 대국 + SF | 강도 제한 Stockfish는 사람과 다르다. Elo는 이 조건 안에서만 비교한다 | 필수 후보 |
| C3 | 베이스 기준 regret | val에서 regret, regret_top1, band_violation을 잰다. 기준선이 있다 | 즉시 | 동결 베이스로 베이스 쪽 수를 채점하므로 베이스의 맹점을 잡지 못한다 | 필수 후보 (단독 판정 불가) |
| C4 | Stockfish 기준 수 품질 | 같은 국면의 수를 Stockfish로 평가해 평균 손실과 큰 실수 비율을 잰다. C3의 순환을 없앤다 | SF | 라벨링 비용이 있다. 표본으로 제한한다 | 필수 후보 |
| C5 | 전술 퍼즐 정답률 | 공개 Lichess 퍼즐의 정답률을 난이도별로 베이스와 비교한다. 원 논문도 쓴 방식이다 | 퍼즐 데이터와 실행기 | 대국 기력과 같지 않다. 데이터 라이선스를 확인해야 한다 | 보조 |
| C6 | 대국 중 국면의 수 품질 | val이 아니라 모델이 스스로 만난 국면의 regret과 큰 실수 비율을 잰다. 학습 분포 밖의 약화를 잡는다 | 대국 (SF 권장) | 상대에 따라 국면 분포가 달라진다 | 보조 |
| C7 | 승리 전환·반복 무승부 | 유리한 국면의 승리 전환율, 3회 반복 무승부 비율을 잰다. FEN만 보는 모델의 한계(Task #7)가 성적을 얼마나 왜곡하는지 본다 | 대국 | 정의에 평가 임계값이 필요하다 | 보조 |

C1·C2 공통으로 고정할 조건: 수 선택 방식(π 샘플링 T = 0.02 또는 최선수), 오프닝 세트, 대국 수, 반복·50수 처리.

### 주장 D: 인과

| # | 수단 | 방법 | 필요 | 한계 | 역할 |
|---|---|---|---|---|---|
| D1 | 기력 항 ablation | 탈, α*에서 λ = 0(R7)과 λ = 1을 비교한다 (6.1) | 학습 + 대국 | 탈 한 기사, α 하나에서만 잰다 | **필수 후보** |
| D2 | α 스윕 곡선 | α = 0, a₁, a₂에서 (스타일 발현, 기력 하락) 곡선을 그리고, 기사를 겹친다 (4.5) | 특성 + 학습 + 대국 | 기사당 점이 3개뿐이다 | 필수 후보 |
| D3 | 곡선 우위 비교 | λ = 0 한 점(R7)을 λ = 1 곡선에서 스타일 발현이 같은 위치와 비교해, 기력 손실이 큰지 본다 (D1과 D2의 결합) | D1 + D2 | R7의 스타일 발현이 λ = 1 곡선 구간 안에 있어야 한다. 밖이면 판정 보류 | 필수 후보 |
| D4 | 용량 반응 | λ, τ를 단계적으로 바꾸어 band_violation과 스타일이 단조로 반응하는지 본다 | 학습 | 비용이 크다 | 보조 (학습하지 않음) |
| D5 | 어댑터 강도 보간 | 학습한 LoRA 보정에 0~1 배율을 곱해 스타일과 regret의 반응을 본다. 재학습이 없다 | 코드 소폭 추가 | 학습 시 α 조절과 같은 현상이 아니다 | 보조 |
| D6 | 방향 통제 (분석) | α = 0에서 α > 0으로 갈 때의 특성 이동 방향을 구하고, 그 방향과 w_p의 코사인을 무작위 단위 벡터들과의 코사인 분포와 비교한다. 학습한 어댑터로 계산하며 추가 학습은 없다 | 특성 + D2 | 무작위 방향으로 학습한 통제군보다 약한 증거다 | 필수 후보 |
| D7 | 기사 라벨 통제 | 세 기사를 합친 기보로 공통 어댑터를 학습하거나 대국별 기사 라벨을 섞어 학습한다. 공통 몫(지금 72~79%)이 어디까지 설명되는지 재서 B를 보강한다 | 학습 | 데이터 크기가 달라져 조건을 맞춰야 한다 | 보조 (학습하지 않음) |
| D8 | seed 변동 대비 효과 | R1·R2와 기존 어댑터 쌍에서 잰 seed 분산을 α > 0에도 적용해, D1·D2의 효과가 그보다 큰지 본다. α에 대한 단조 반응을 보조 증거로 쓴다 | B3 결과 | α > 0에서도 seed 분산이 α = 0과 같다고 가정한다. 이 가정을 기준 문서에 적는다 | 필수 후보 |

**비교군 조건**: 지금 어댑터는 Task #5 수정 전 코드로 학습되었다. D의 비교에는 현재 코드로 학습한 어댑터(R1~R7)끼리 비교한다. 기존 어댑터는 B3의 잡음 바닥 쌍에만 쓴다.

## 학습 설계 (후속 타스크 입력)

학습 1회가 여러 비교군을 겸하도록 짠다. 이번 타스크에서는 학습하지 않고, 기준 문서에 요구 사항으로 적는다. 추가 학습은 10회, 약 30~36시간이다 (1회 3~3.6시간, Task #2·#4 실측. 카르포프는 데이터가 조금 더 많아 더 걸릴 수 있다).

| 학습 | 기사 | 설정 | 맡는 역할 | 시점 |
|---|---|---|---|---|
| R1 | 탈 | α = 0, λ = 1, seed 1 | B3 잡음 바닥, D의 같은 코드 기준선, D2의 α = 0 점, D8 seed 분산 | 지금 가능 |
| R2 | 스미슬로프 | α = 0, λ = 1, seed 1 | R1과 같다 | 지금 가능 |
| R3, R4 | 탈 | α = a₁, a₂, λ = 1 | 주 결과(A·B·C 평가 대상), D2 곡선, D6 | 특성 구현 뒤 |
| R5, R6 | 스미슬로프 | α = a₁, a₂, λ = 1 | R3, R4와 같다 | 특성 구현 뒤 |
| R7 | 탈 | α = α*, λ = 0 | D1 ablation, D3 | 특성 구현 뒤 |
| R8 | 카르포프 | α = 0, λ = 1, seed 1 | R1과 같다 | 지금 가능 |
| R9, R10 | 카르포프 | α = a₁, a₂, λ = 1 | R3, R4와 같다 | 특성 구현 뒤 |

- 공통 설정은 Task #2~#4와 같다 (rank 16, 학습률 1e-4, 3 epoch, 배치 32국면, τ = 0.02). R3~R7, R9, R10의 seed는 1로 고정한다.
- D1 ablation(R7)은 탈에서만 한다. 세 기사 중 스타일과 기력이 가장 상충하기 쉬운 쪽이다 (희생 성향).
- α*는 a₁, a₂ 중 주 결과로 보고할 값이다. α 값과 α*를 고르는 규칙은 α > 0 결과를 보기 전에 고정한다.
- GPU 메모리(학습 1회 7.86 GiB, 카드 12 GiB)로 두 학습을 동시에 돌릴 수 없다.
- 학습하지 않는 수단: B13, D4, D7, 무작위 방향 학습 통제군.
- 베이스는 기존 어댑터와 같은 136M이다.

### GPU 서버 학습 디렉토리 요구 사항 (`gpu_train/`, 후속 이슈에서 작성)

학습은 별도 GPU 서버에서 한다 (작업지시자 결정, 2026-11-04). 기준 문서의 학습 설계 절에 다음 요구 사항을 적고, 디렉토리는 후속 이슈에서 만든다.

| 항목 | 요구 사항 |
|---|---|
| 실행 환경 | 학습 전용 Dockerfile과 compose 파일. 로컬 개발용 `docker/`와 분리하고 개발 도구(클로드 코드 등)는 넣지 않는다. 호스트에 NVIDIA 드라이버와 Container Toolkit이 있어야 한다 |
| 입력 | 베이스 `base_model/136M.pt`, 전처리 데이터와 베이스 q 캐시(`data/processed/`). 서버로 옮기는 방법과 체크섬 확인 방법을 적는다 |
| 학습 목록 | R1~R10을 ID별 설정(기사, α, λ, τ, seed)으로 정의한다. 지금은 α = 0인 R1·R2·R8만 실행할 수 있고, 나머지는 특성 구현 뒤 같은 형식으로 추가한다 |
| 실행 | 학습 ID 하나로 실행하는 스크립트. 기존 `train_player.sh`처럼 오류가 나면 마지막 체크포인트에서 자동 재개하고, `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`를 쓴다 |
| 기록 | 코드 커밋 해시, 설정, GPU 종류와 메모리, 시작·종료 시각, 재개 횟수를 출력 폴더에 남긴다 |
| 결과 회수 | 회수할 파일(어댑터, `config.json`, 로그, val 지표)과 형식을 정한다. 사용자가 결과를 `mydocs/test_result/`에 저장한다 (CLAUDE.md) |
| 사전 확인 | 짧은 시험 학습(smoke)으로 GPU 메모리와 처리량을 확인한 뒤 본 학습을 시작한다 |
| 매뉴얼 | 위 절차를 `gpu_train/README.md`에 한국어로 적는다 |

## 공통 조건 (전 주장)

- **표본 분리**: 학습 신호로 스스로를 채점하지 않는다. w_p 추정과 평가에 같은 표본을 쓰지 않는다
- **통계**: 국면이 아니라 대국 단위로 부트스트랩한다 (val은 기사당 117~129국, Task #6과 같은 방식)
- **구간 보고**: 전체와 ply 20 이상을 함께 보고한다. 오프닝 레퍼토리 효과는 Task #6에서 확인했다
- **기력과 동반**: 스타일 지표는 C의 결과 없이 성공으로 판정하지 않는다 (제안서 6.1)
- **기준 고정과 변경**: 값은 α > 0 결과를 보기 전에 고정한다. 나중에 바꾸면 이유와 날짜를 "정정"으로 남기고 바꾸기 전 기준의 판정도 함께 보고한다

## 기준 문서에 담을 내용

주장 A~D마다 같은 형식으로 쓴다.

1. 주장과 틀렸다고 볼 상황
2. 채택한 수단과 뺀 수단, 그 이유
3. 지표 정의: 계산식, 입력, 표본, 집계 단위, 통계 처리, 기준선
4. 판정: 통과·실패·판정 보류 조건과 근거
5. 고정 시점: 값을 지금 정할 수 없는 항목은 어떤 측정으로 언제 고정할지
6. 기사 범위: 세 기사 모두 필수다. 탈·스미슬로프 복잡도 축(B8)과 카르포프 관련 판정을 구분해 적는다

문서 끝에는 주장 네 개의 판정을 합쳐 연구 목표 전체의 성공을 판단하는 규칙과, 후속 타스크에 필요한 도구·자원 추정을 둔다. 제안서와 달라지는 부분(지문 거리를 모델 지문 기준으로 판정 등)은 차이와 이유를 적는다. `README.md` 문서 표에 링크를 한 줄 추가한다.

## 예상 단계: 4단계

주장별로 수단을 추리고 판정을 확정한다. 단계마다 기준 문서의 해당 절을 완성해 승인받는다.

1. **주장 A 재현**: 수단 채택, 지표 정의, 판정 기준
2. **주장 B 분리**: 수단 채택, 지표 정의, 판정 기준 (모델 지문, 순환 방지, seed 잡음 바닥)

4. **주장 D 인과와 문서 확정**: 수단 채택, 판정 기준, 종합 판정 규칙, 후속 입력, README 갱신, 기준 고정

## 위험과 대응

| 위험 | 대응 |
|---|---|
| 데이터 없이 임계값을 정하면 근거가 약하다 | 우연 수준, 측정 오차, seed 변동 같은 근거를 값과 함께 적는다. 근거가 없으면 실측 뒤 고정으로 두고, α > 0 결과 전에 고정한다 |
| 수단이 많아 비용이 감당되지 않는다 | 단계마다 필수를 최소로 추린다. 학습은 "학습 설계" 절의 7회로 제한하고, 대국 수를 합산해 4단계에 적는다 |

| 기준이 엄격해 연구 목표가 성립하지 못한다 | "실패"와 "판정 보류"를 구분하고, 실패도 연구 결과로 보고할 수 있게 쓴다 |
| 특성 벡터가 없어 B·D 기준이 정의에 의존한다 | 특성에 의존하지 않는 수단(B3, B10, C1, D1)을 함께 둔다 |
