# 평가 진행 요약 보고서 (2026-11-16 기준)

> 이 문서는 프로젝트를 처음 보는 사람도 읽을 수 있도록 썼다. 용어는 2절에서 풀어 설명하고, 결과마다 "무슨 뜻인가"를 붙였다. 정확한 수치와 근거는 끝의 출처 문서에 있다.

## 1. 이 프로젝트는 무엇을 하나

### 한 줄 요약

**체스 AI에 특정 세계 챔피언의 "두는 스타일(기풍)"을 입히되, 실력은 떨어뜨리지 않는 것이 목표다.** 지금은 그 결과를 공정하게 채점하는 단계에 있다.

### 조금 더 자세히

- **출발점 (베이스 모델)**: DeepMind가 공개한 Transformer 체스 모델(1억 3,600만 파라미터, "136M")을 쓴다. 이 모델은 수읽기(탐색) 없이, 국면을 한 번 보고 수마다 "이 수를 두면 이길 확률"을 바로 내놓는다. 이 값이 가장 높은 수를 두는 식으로 체스를 둔다.
- **기풍 입히기 (어댑터)**: 세 기사의 실제 기보로 베이스 모델을 조금씩 고쳐, 그 기사가 둘 법한 수를 더 좋아하도록 만든다.
  - 세 기사: **탈**(공격적, 희생을 즐김), **카르포프**(위치적, 조여 가는 스타일), **스미슬로프**(조화롭고 담백한 스타일)
  - 모델 전체를 다시 학습하지 않고, 작은 추가 부품(**LoRA 어댑터**)만 학습해 붙인다. 그래서 "베이스 + 탈 어댑터"처럼 갈아 끼울 수 있다.
- **평가가 필요한 이유**: "탈처럼 두게 됐다"는 말은 그럴듯하게 들리기 쉽다. 그래서 **결과를 보기 전에 채점 기준을 먼저 고정**하고(2026-11-04), 그 기준대로 기계적으로 판정한다. 결과를 본 뒤 기준을 바꾸면 원하는 결론을 끼워 맞출 수 있기 때문이다.

|---|---|---|

| Task #6 | 세 어댑터 비교 | 각 어댑터가 자기 기사의 수를 가장 잘 맞히는지 처음 확인했다 |
| Task #9 | 평가 기준 작성·고정 | "무엇을, 어떻게 재서, 몇 점이면 통과인가"를 미리 정했다 |

## 2. 먼저 알아 둘 용어

| 용어 | 뜻 |
|---|---|
| **국면** | 체스판의 한 장면. 평가는 기사의 실제 대국에서 뽑은 국면 13,846개(368국)로 한다 |
| **val (검증 데이터)** | 학습에 쓰지 않고 따로 떼어 둔 기보 (각 기사 대국의 5%). 시험 문제를 미리 보지 못하게 한 것과 같다 |
| **ply** | 한쪽이 한 번 두는 것. 백 1수 + 흑 1수 = 2 ply. **ply 20 이상**은 오프닝(초반 정석)을 지난 중반 이후다 |
| **top1 (1순위 일치율)** | 모델이 가장 두고 싶어 한 수가 기사가 실제로 둔 수와 같은 비율. 높을수록 좋다 |
| **imitation (모방 손실)** | 기사가 실제로 둔 수를 모델이 얼마나 "예상 밖"으로 보는지를 나타내는 값. 낮을수록 기사를 잘 흉내 낸다 |
| **regret (아쉬움)** | 모델이 고른 수가 최선의 수보다 승률을 얼마나 깎는지. 기준은 베이스 모델의 판단이다. 낮을수록 좋다 |
| **α (알파)** | 기풍을 얼마나 세게 넣을지 정하는 손잡이. **지금까지는 모두 α = 0**이다. 이는 기사의 수를 흉내 내는 학습만 한 상태이며, 기풍을 따로 강조하는 장치는 아직 켜지 않았다는 뜻이다. 그래서 지금 결과는 앞으로 비교할 **기준선**이다 |
| **seed (시드)** | 학습의 무작위성(데이터 순서 등)을 정하는 번호. 같은 데이터로 seed만 바꿔 다시 학습하면 결과가 조금 달라진다. 이 차이가 "우연의 크기(잡음)"다 |
| **R1 · R8 · R2** | 탈 · 카르포프 · 스미슬로프 어댑터 (seed 1). **R1s0 · R8s0 · R2s0**은 seed만 0으로 바꾼 쌍둥이 |
| **신뢰 구간** | 표본을 바꿔도 결과가 얼마나 흔들리는지 보여 주는 범위. 대국을 무작위로 다시 뽑아 10,000번 계산하는 방식(부트스트랩)으로 구했다. 예: "+0.05 [+0.04, +0.07]"은 값이 +0.05이고, 우연을 감안해도 +0.04~+0.07 사이라는 뜻이다 |
| **통과 / 실패 / 판정 보류** | 구간 전체가 기준을 넘으면 **통과**, 구간 전체가 기준에 못 미치면 **실패**, 구간이 기준에 걸쳐 있으면 **판정 보류**(아직 어느 쪽이라고 말할 수 없음)다 |

## 3. 무엇을 채점하나: 네 가지 질문

연구 목표를 네 가지 질문으로 나눠 따로 채점한다.

| 질문 | 쉬운 말로 | 현재 상태 |
|---|---|---|
| **A 재현** | 탈 어댑터가 원래 모델보다 실제 탈에 더 가까워졌나? | 대국 없이 잴 수 있는 부분 통과 |
| **B 분리** | 세 어댑터가 서로 다른 스타일인가? 아니면 다 비슷하게 "사람처럼" 될 뿐인가? | 판정 보류 (신호가 약함) |
| **C 기력** | 스타일을 넣고도 실력이 유지되나? | 일부만 측정. 대국 채점 도구 제작 중 |
| **D 인과** | 그 결과가 우리가 설계한 장치(기풍 강조, 실력 유지) 덕분인가? | 아직 시작 전 (α > 0 학습이 필요) |

## 4. 지금까지의 결과 (α = 0 기준선)

### 4.1 기사 흉내는 확실히 좋아졌다

| | 탈 | 카르포프 | 스미슬로프 |
|---|---|---|---|
| 1순위 일치율: 베이스 → 어댑터 | 60.6% → 65.8% | 55.9% → 60.9% | 56.4% → 63.2% |
| 모방 손실 감소 | −26% | −23% | −25% |

- **뜻**: 어댑터를 붙이면 기사가 실제로 둔 수를 5~7%p 더 자주 맞힌다.
- 학습에서 한 번도 본 적 없는 국면(새 국면)에서도 개선이 남았다. 기보를 외운 것이 아니라 일반화했다는 증거다.
- 서버에서 다시 학습해도 값이 거의 같게 재현됐다.

### 4.2 첫 공식 채점 (Task #12)

| 항목 | 무엇을 봤나 | 판정 | 핵심 값 (탈 / 카르포프 / 스미슬로프) |
|---|---|---|---|
| A1 | 어댑터가 베이스보다 기사의 수를 더 맞히나 | **통과** ×3 | 1순위 일치율 +5.2 / +5.0 / +6.8 %p |
| A2 | 학습에 없던 새 국면에서도 그런가 | **통과** ×3 | +1.7 / +1.2 / +4.3 %p |
| A3 | 어댑터와 베이스가 다른 수를 골랐을 때, 누가 더 자주 맞나 | **통과** ×3 | 의견이 갈린 국면 100개마다 "어댑터만 맞힘"이 "베이스만 맞힘"보다 22.8 / 17.9 / 24.8개 많음 |
| B3 | 세 어댑터의 차이가 우연(seed) 차이보다 큰가 | **통과** | 기사 사이 차이가 우연 차이의 약 15배 |
| B10 3지선다 | 대국 하나를 보여 주고 "셋 중 누구 대국?"을 맞히나 | **통과** | 정답률 45.7 / 43.4 / 59.4% (찍기 33%) |
| B10 2지선다 | 두 기사 중 누구인지를 맞히나 | **판정 보류** ×3 | 모두 50%(찍기)보다 높지만, 구간 하한이 50% 아래 |
| C3 | 고른 수가 승률을 얼마나 깎나 | **통과** ×3 (이것만으로 기력 판정은 못 함) | 0.28 / 0.26 / 0.30 %p (허용 한계 2%p) |

**종합**
- **A (재현)**: 부분 통과. 대국 없이 잴 수 있는 항목은 모두 통과했다. 나머지(A5·A6)는 스타일 특징을 수치로 만드는 작업(후속 과제)이 끝나야 잴 수 있다.
- **B (분리)**: 판정 보류. 실패한 항목은 없다. 다만 2지선다에서 확신할 만큼 신호가 강하지 않았다.
- **C (기력)**: 지금까지 잰 범위에서는 실력이 떨어진 신호가 없다. 실제 대국 성적은 아직 재지 않았다.

## 5. 결과에서 알게 된 것

1. **흉내(A)는 확실하다.** 새 국면에서도 개선이 유지된다.
2. **스타일 구분(B)은 방향은 맞지만 아직 약하다.** 2지선다 정답률이 모두 50%를 넘지만, 기사당 대국이 120국 안팎이라 우연을 배제하기에는 부족하다. 확신하려면 정답률이 약 59% 이상이어야 한다.
3. **구분 신호의 상당 부분이 오프닝에 있다.** 대국 전체로 보면 2지선다도 76~82%로 통과한다. 그러나 오프닝은 기사가 외워 둔 정석일 가능성이 커서, 기준은 진짜 스타일을 보려고 중반 이후(ply 20 이상)로 판정한다. 그 구간에서는 신호가 약해진다.
4. **카르포프가 가장 구분하기 어렵다.** 여러 지표에서 가장 약했다. 기준을 만들 때 미리 예상한 결과와 같다.
5. **우연(seed)의 영향은 작다.** 다만 기준 경계에 가까운 항목(A2, B10)은 쌍둥이 모델에서 통과와 보류가 바뀌기도 했다.
6. **실력 저하 신호는 없다.** 어댑터가 고른 수가 승률을 깎는 정도는 오히려 베이스보다 작았다.

## 6. 지금 하고 있는 일 (Task #13: 대국 채점 도구)

질문 C(기력)를 제대로 판정하려면 실제로 대국을 두어 봐야 한다. 그 도구를 만들고 있다.

| 채점 | 방법 |
|---|---|
| **C1** | 어댑터와 원래 모델을 400판 맞붙인다 |
| **C2** | 어댑터와 원래 모델이 각각 같은 상대(체스 엔진 **Stockfish**, 실력을 일부러 제한함)와 400판을 두어 성적을 비교한다 |
| **C4** | Stockfish가 매긴 점수로, 어댑터가 고른 수가 최선의 수보다 얼마나 나쁜지 잰다. 원래 모델과 비교한다 |

- 통과 기준: 실력 하락이 **Elo 50점 이내**(체스 등급 점수, 50점 차이는 승률 약 43% 대 57%)여야 한다. C4는 승률 손실 차이가 2%p 이내여야 한다.
- **공정한 시작 국면**: 기사의 레퍼토리와 무관한 공개 오프닝 200개에서 시작한다. 엔진 평가로 거의 동등한(±0.5폰) 국면만 골랐고, 같은 오프닝을 흑백을 바꿔 두 번씩 둔다.
- **진행 상황**: 도구 제작과 검증(테스트 313개 통과)을 마쳤다. 지금은 GPU 서버에서 Stockfish의 실력을 원래 모델과 비슷하게 맞추는 **보정 대국**을 준비하고 있다. 로컬 시험에서는 Stockfish가 1만 노드만 읽어도 원래 모델을 10판 모두 이겨, 더 약한 설정을 찾는 중이다.
