# Task #11 최종 결과보고서: α = 0 학습 R1·R2·R8 (GPU 서버)

## 개요

평가 기준 문서 8.1절의 α = 0 학습 R1(탈)·R2(스미슬로프)·R8(카르포프) 결과를 회수했다. 무결성과 설정을 확인했고, GPU 서버에서 재평가해 학습 기록과 차이 0으로 재현되는 것을 확인했다. 잡음 바닥 쌍을 위해 seed 0 대조군 R1s0·R2s0·R8s0을 현재 코드로 서버에서 새로 학습했다. 기준 문서의 B3·D8 쌍을 이 학습으로 정정했다. 결과는 `mydocs/test_result/task_m100_11_test.md`에 정리했다.

이로써 수행 계획서의 끝 상태에 도달했다. 후속 이슈 "특성 없는 평가"(8.3절 순서 3)는 `runs/gpu/` 아래의 어댑터 6개를 바로 쓸 수 있다. `src/`는 바꾸지 않았다.

## 발견 사항

1. **서버 학습은 로컬 추정의 약 2.5~2.8배 걸린다.** R1·R2·R8 합계 27시간 19분이다(A2000). 기준 문서 8.1·8.4절을 정정했다. 남은 7회(R3~R7, R9, R10)는 A2000 기준 약 63시간이다(스타일 항 비용 제외).
2. **서버에 GPU 기종이 다른 계산 노드가 있다.** `moana-u1`은 RTX A2000, `moana-u8`은 RTX 2080 Ti다. 제출 스크립트가 노드를 지정하지 않아, seed 0 학습 일부가 `moana-u8`에 배정됐다.
   - `moana-u8`에서는 학습이 약 4국면/초로 A2000의 약 0.37배다. 평가(float32)는 반대로 2.5~3배 빠르다. bfloat16 텐서 코어가 없어 AMP 학습이 느린 것으로 보이나 확인하지 않았다
   - 카르포프 학습 1회가 20시간 제한을 넘는다. seed 0 3회는 실제로 47시간 37분 걸렸다
3. **seed 쌍 중 둘에 GPU 기종 차이가 섞인다.** (R2s0, R2)는 GPU까지 같다. (R1s0, R1)은 2080 Ti와 A2000이다. (R8s0, R8)은 마지막 439 step만 같은 A2000에서 학습했다. torch·코드·입력·baseline은 같다. 재학습하지 않고 기록만 했다 (작업지시자 결정, 2026-11-12).
4. **같은 서버·같은 GPU 기종에서는 평가가 비트 단위로 재현된다.** 받은 어댑터가 학습 끝의 가중치 그대로라는 것도 확인했다.
5. **마지막 val 지표의 seed 차이는 기존 seed 0 때보다 작아지지 않았다.** 예를 들어 탈 top1 차이는 기존 seed 0과 +0.0044, R1s0과 +0.0062다. B3 판정은 정책 거리로 하므로 후속 이슈에서 잰다.
