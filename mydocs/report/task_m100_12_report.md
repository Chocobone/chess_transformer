# Task #12 최종 결과보고서: 특성 없는 평가 (A1~A3, B2·B3·B10, C3)

## 개요

평가 기준 문서 `mydocs/tech/evaluation_criteria.md`의 지표 중 특성(f(s,a), w_p)과 대국이 필요 없는 것을 `src/eval/` 패키지로 구현했다. 이 코드는 GPU 서버의 모델 출력 덤프와 CPU의 지표·부트스트랩·판정으로 나뉜다. α = 0 어댑터 R1·R8·R2와 seed 0 대조군 R1s0·R8s0·R2s0을 평가했다.

판정 결과는 다음과 같다.

- **특성 없는 A**: 부분 통과. A1~A3는 세 기사 모두 통과했고, A5·A6는 특성이 필요해 판정 보류다
- **특성 없는 층 B**: 판정 보류. B3와 B10 3지선다는 통과했지만, B10 쌍별 2지선다 세 쌍이 모두 판정 보류다
- **C3**: 세 기사 모두 통과 (단독 판정 불가)

결과는 `mydocs/test_result/task_m100_12_test.md`에 정리했다. 같은 코드로 α > 0 어댑터도 덤프만 더해 평가할 수 있다. 이로써 수행 계획서의 끝 상태에 도달했다.

## 발견 사항

1. **특성 없는 층 B의 판정 보류는 신호가 약하기 때문이고, 반대 방향의 결과는 아니다.** 쌍별 2지선다 6개 재현율 점추정이 모두 1/2보다 크다. 기사당 116~128국에서는 구간 폭이 약 ±0.09라, 하한이 1/2을 넘으려면 점추정이 대략 0.59 이상이어야 한다. 쌍별에는 실패 조건이 없어 통과가 아니면 보류가 된다.
2. **기사 구별 신호의 상당 부분이 오프닝에 있다.** 전체 ply로 재면 쌍별 세 쌍이 모두 통과한다(재현율 0.76~0.82). A3 불일치 국면도 ply 0~9에 몰린다(0.20 대 전체 0.12~0.15). 기준 문서는 기풍을 보려고 ply ≥ 20으로 판정한다.
3. **카르포프가 가장 약하다.** B10 3지선다 재현율이 가장 낮고, 막힌 쌍별 세 값 중 두 개가 카르포프다. ply ≥ 20 기사 특이 몫(12.1%)과 ply ≥ 20 Δtop3(구간이 0 포함)도 가장 약하다. 기준 문서 4.8절의 예상과 같다.
4. **seed 잡음은 작고, 학습 GPU 기종 차이도 잡음을 키우지 않았다.** n_p는 기사 사이 거리 d의 약 1/15이다. 기종이 다른 seed 쌍(R1s0-R1, R8s0-R8)과 같은 쌍(R2s0-R2)의 n_p가 비슷하다. 다만 경계 근처의 지표(A2, B10)는 seed에 따라 통과와 보류가 바뀐다. seed 0이면 탈·카르포프의 A2 구간이 0을 포함하고, B10 3지선다도 판정 보류다.
5. **현재 코드의 α = 0 기준선은 Task #6(기존 어댑터)과 거의 같다.** B1 imitation 차이는 가장 커도 0.0070이고, 기사 특이 몫 차이는 ±1.1%p 안이다.
6. **재현율 구간은 k/n 격자 위에 있다.** 전체 ply 쌍별에서 맞힌 수가 같은 두 쌍이 구간까지 같게 나왔다. 독립 재계산으로 맞힌 대국 집합이 서로 다른 우연임을 확인했다.

## 계획 대비 차이

1. **국면별 지표 함수를 1단계에 넣었다** (1단계 보고서). 덤프 자체로 학습 기록을 대조하려면 필요했다
2. **분석은 개발 컨테이너에서 한다.** 호스트 Python에 numpy가 없다. 분석 모듈은 torch를 쓰지 않는다
3. **베이스 정책은 CPU에서 계산한다.** 학습 baseline 줄과 대조해 통과했다
4. **2단계 추가 해석 4건(8~11)** 을 승인받아 반영했다
5. **`base.json`은 만들지 않았다.** 베이스 대조는 각 모델 json의 `baseline` 항목에 있다 (4단계)
6. 덤프 시간은 예상(약 4.2시간)과 비슷한 4시간 16분이었다

## 후속 과제

- **특성 없는 층 B의 판정 보류 처리**: 기준 정정(판정 구간, k, 쌍별 조건)이나 val 확대가 필요하다. 정정한다면 2.7절 절차로 α > 0 결과가 나오기 전에 해야 한다 (작업지시자 결정 사항)
- 기준 문서 8.3절 순서 4~7의 후속 이슈 (특성과 w_p, 대국 실행기, α > 0 학습, 평가 실행과 판정). α > 0 평가는 이 타스크의 덤프·판정 코드를 그대로 쓴다
