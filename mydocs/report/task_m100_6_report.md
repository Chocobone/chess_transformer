# Task #6 최종 결과보고서: 세 기사 136M 어댑터 학습 결과 종합, 실행 가이드 갱신

## 개요

탈(Task #2)·카르포프(Task #3)·스미슬로프(Task #4)의 136M LoRA 어댑터 학습 결과를 같은 기준으로 모아 `mydocs/tech/adapters_136M_summary.md`에 정리했다. 기준 문서에는 데이터, 설정, val 지표와 곡선, 운영 수치, 조건 차이, val·train 겹침, 교차 평가, 요약과 한계를 담았다.

각 어댑터를 세 기사의 val에 평가하는 교차 평가(GPU 29분)도 처음으로 했다. 세 val 모두에서 자기 기사의 어댑터가 기사의 수를 가장 잘 맞혔다. 다만 개선의 72~79%는 세 어댑터에 공통이었다.

세 학습의 운영 경험으로 실행 가이드를 갱신했다. 기존 기록에서 찾은 GPU 사용량 단위 오류(MiB÷1000을 GiB로 표기)는 13개 문서, 34곳을 정정했다.

## 주요 결과

### 1. 세 어댑터 (val 전체, 기준선 → 최종)

| | 탈 | 카르포프 | 스미슬로프 |
|---|---|---|---|
| 국면 train / val | 79,493 / 3,880 | 96,393 / 5,213 | 93,178 / 4,753 |
| imitation | 1.4369 → 1.0661 (−25.8%) | 1.4941 → 1.1516 (−22.9%) | 1.4497 → 1.0936 (−24.6%) |
| top1 | +4.77%p | +4.74%p | +6.96%p |
| regret_top1 | 0 → 0.0029 | 0 → 0.0027 | 0 → 0.0029 |
| step 1000까지의 개선 비율 | 68.8% | 71.0% | 68.7% |
| 전체 소요 | 3시간 8분 | 7시간 18분 (평가 지연) | 3시간 37분 |

- 설정은 `config.json` 38개 키 중 데이터에 따라 정해지는 5개만 다르다.
- 과적합 신호는 없다. 2 epoch 시점에 개선의 99% 이상이 이미 났다.
- 기력 쪽 지표 가운데 나빠진 것은 `regret_top1`뿐이다. regret, band_violation, strength는 기준선보다 좋아졌다.

### 2. 교차 평가 (imitation, 행 어댑터, 열 val)

| 어댑터 \ val | 탈 | 카르포프 | 스미슬로프 |
|---|---|---|---|
| 기준선 | 1.4369 | 1.4941 | 1.4497 |
| 탈 | **1.0661** | 1.2299 | 1.1901 |
| 카르포프 | 1.1741 | **1.1516** | 1.1981 |
| 스미슬로프 | 1.1567 | 1.2182 | **1.0936** |

- 대각선은 학습 마지막 eval과 7개 지표 모두 차이 0이다.
- **자기 어댑터가 가장 좋다.** 대국 단위 부트스트랩 95% 구간이 모두 0을 포함하지 않는다. 오프닝 대부분을 뺀 ply 20 이상에서도 같다.
- **개선의 대부분은 공통이다.**
  - 다른 기사 어댑터도 얻는 몫이 72~79%다 (ply 20 이상 78~89%).
  - 기사 특이 몫은 21~28%다 (ply 20 이상 11~22%).
  - 카르포프가 가장 덜 갈라진다. ply 20 이상에서 top1 우위의 구간은 0을 포함한다.
- 자기 어댑터 우위의 일부는 오프닝 레퍼토리다. val이 자기 train과 겹치는 비율이 다른 기사보다 4~8%p 크고, ply 20 이상에서는 우위가 37~63% 줄어든다.
- regret은 모든 val에서 탈 어댑터 > 카르포프 어댑터 > 스미슬로프 어댑터 순이다. 기풍 차이를 뜻하는지는 이 지표로 알 수 없다.
- 이 결과는 모방 지표다. 기풍 분리의 증거(지문 거리·혼동 행렬)로 내세우지 않는다.

### 5. GPU 사용량 단위 정정

- 학습 중 60초 GPU 기록(MiB)을 1000으로 나눠 GiB로 적은 값이 Task #2~#4 문서 13개, 34곳에 있었다. 1024로 나눈 값과 MiB 값을 정정 표시로 붙였다.
  - 예: 카르포프 "11.9 GiB"는 11.5~11.7 GiB, 탈 "9.98 GiB"는 9.75 GiB, 스미슬로프 "6.07 GiB"는 5.92 GiB.
- 결론은 바뀌지 않는다. Task #4 사전 측정 값과 판정은 처음부터 맞았다.
- 원 기록이 없어 확인할 수 없는 값 4개는 목록으로 남겼다.

## 남은 일과 한계

- 세 어댑터는 같은 조건의 끊기지 않은 학습 결과가 아니다 (재개 구간의 데이터 순서). 성능 영향은 실측하지 않았다.
- 136M, seed 하나의 결과다. seed 변동은 재지 않았다.
- 교차 평가 스크립트는 저장소 밖에 있다. α 스윕 등에서 반복해서 쓰게 되면 정식 도구(`scripts/`)로 넣을지 정해야 한다.
- 이월된 다음 일은 다음과 같다.
  - CUDA 오류 원인 조사 (보류)
  - 270M 학습
  - 스타일 특성 벡터 f(s,a)와 방향 벡터 w_p
  - α 스윕과 평가 (지문 거리·혼동 행렬·대국 성적)
- 기사 특이 몫이 작다(ply 20 이상 11~22%). 그래서 스타일 항(α > 0)이 기사 간 차이를 얼마나 키우는지가 다음 단계의 핵심 측정이 될 것이다. 이번 3×3 표가 그 비교의 출발점(α = 0)이다.
