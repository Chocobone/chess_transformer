# Task #9 최종 결과보고서: 기풍 주입 평가 기준 작성

## 개요

제안서의 연구 목표를 주장 네 개(A 재현, B 분리, C 기력, D 인과)로 나눴다. 주장마다 검증 수단, 지표 정의, 통과·실패·판정 보류 조건을 정해 기준 문서 `mydocs/tech/evaluation_criteria.md`로 고정했다(2026-11-04). 스타일 항 학습(α > 0), α 스윕, 대국 평가를 실행하기 전에 기준을 고정해, 결과를 본 뒤 기준을 맞추는 일을 막는다. 이번 타스크는 문서만 썼다. 코드 수정, 학습, 평가 실행은 하지 않았다.

## 발견 사항

1. **기존 어댑터를 잡음 바닥에 재사용할 수 있다.** Task #5 결함으로 기존 어댑터와 현재 코드 어댑터는 데이터 순서와 일부 국면의 학습 횟수(0.83~12.45%)만 다르다. 이것은 seed 잡음과 같은 종류다. 그래서 기존 seed 0과 새 seed 1을 잡음 바닥 쌍으로 쓰고 기사당 학습 1회를 줄였다. 잡음이 크게 잡히는 방향이라 B 판정에는 보수적이다.
2. **특성 있는 지표는 α > 0에서 본질적으로 순환이 있다.** 스타일 항이 w_p · f̃를 키우도록 학습하므로, 특성 있는 지표(B8, B6, B4, D2, D6)는 "의도한 축에서 벌어졌는가"까지만 판정한다. 실제 기사와 닮았는지는 w_p를 쓰지 않는 A5(실제 수 평균까지의 거리), A6, B10이 맡는다.
3. **카르포프의 방향에 대응하는 특성 성분이 없다.** "견고·질식"은 제안서 특성 4성분에 없다. 그래서 제안서 6.3의 예측("카르포프가 탈과 스미슬로프 사이")을 모델 지문 순서로 검정한다(B4). 실제 기사 지문이 이 순서가 아니면 판정 보류다.
4. **평가 표본이 val뿐이라 α*를 결과로 고를 수 없다.** 데이터는 train과 val(5%)뿐이다. 그래서 α* = a₂로 미리 고정하고, w_p와 정규화 통계는 train으로만 추정한다.
5. **카르포프가 B 통과의 병목일 수 있다.** Task #6에서 ply 20 이상 top1 우위 구간이 0을 포함한 것은 카르포프뿐이다. 세 기사 모두 통과해야 하는 규칙이라 그대로 영향을 받는다. 결과를 보기 전의 예상으로 기준 문서 4.8절에 남겼다.
6. **B8의 Stockfish 비용은 학습용 라벨링보다 훨씬 작다.** 두 어댑터의 1순위가 갈리는 국면만 평가하면 약 1만 6천 회다(추정). 학습용 라벨링 추정치는 500만~600만 회다.
