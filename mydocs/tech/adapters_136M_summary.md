## 3. val 지표

val 세트가 기사마다 다르다. 그래서 지표의 절대값으로 기사끼리 순위를 매기지 않는다. 각자의 기준선(베이스 모델) 대비 변화로 본다.

| 지표 | 탈 | 카르포프 | 스미슬로프 |
|---|---|---|---|
| imitation | 1.4369 → 1.0661 (−0.3708, −25.8%) | 1.4941 → 1.1516 (−0.3425, −22.9%) | 1.4497 → 1.0936 (−0.3561, −24.6%) |
| top1 | 0.6062 → 0.6539 (+4.77%p) | 0.5586 → 0.6060 (+4.74%p) | 0.5639 → 0.6335 (+6.96%p) |
| top3 | 0.8688 → 0.8938 (+2.50%p) | 0.8565 → 0.8767 (+2.01%p) | 0.8515 → 0.8908 (+3.93%p) |
| regret | 0.01268 → 0.00991 (−21.8%) | 0.01341 → 0.00914 (−31.8%) | 0.01357 → 0.00883 (−34.9%) |
| regret_top1 | 0 → 0.00286 | 0 → 0.00273 | 0 → 0.00293 |
| band_violation | 0.2528 → 0.1665 (−34.1%) | 0.2658 → 0.1560 (−41.3%) | 0.2701 → 0.1587 (−41.2%) |
| strength | 0.00539 → 0.00457 (−15.2%) | 0.00550 → 0.00368 (−33.0%) | 0.00570 → 0.00337 (−40.8%) |

- 세 어댑터 모두 모방 지표(imitation, top1, top3)가 좋아졌다.
- 기력 쪽 지표 가운데 나빠진 것은 `regret_top1`뿐이다 (0 → 약 0.003). 기준선의 최선수는 정의상 베이스의 최선수라 regret이 0이다. 어댑터의 최선수가 베이스와 다를 때 잃는 승률의 평균이 약 0.3%p라는 뜻이다.
- regret, band_violation, strength는 기준선보다 좋아졌다. 정책이 temperature 0.02의 softmax라서, 기사의 수 쪽으로 확률을 모으면 regret이 큰 수에 실린 확률이 줄어드는 효과로 보인다.

각 어댑터를 세 기사의 val 전체에 평가했다 (2026-10-15, Task #6 2단계). 실행 기록과 전체 표는 `mydocs/test_result/task_m100_6_test.md`에 있다. 대각선 3칸은 학습 마지막 eval과 7개 지표 모두 차이 0이다.

(각 칸의 두 값은 다른 두 어댑터와의 차이다. 탈 val이면 탈−카르포프, 탈−스미슬로프 순이다.)

### 읽은 것

1. **세 val 모두에서 그 기사의 어댑터가 imitation이 가장 좋다.** 차이의 95% 구간은 모두 0을 포함하지 않는다. 오프닝 대부분을 뺀 ply 20 이상에서도 같다. 어댑터는 자기 기사의 수를 다른 기사 어댑터보다 더 잘 맞힌다.
2. **개선의 대부분은 세 어댑터에 공통이다.** imitation 개선에서 다른 기사 어댑터도 얻는 몫이 72~79%(전체), 78~89%(ply 20 이상)다. 기사 특이 몫은 21~28%(전체), 11~22%(ply 20 이상)다. 베이스(ChessBench 승률 모델) 대비 "고전 대국 최상위 인간 기사의 수"로 옮겨 간 부분이 크다.
3. **기사 특이 몫은 오프닝에서 더 크다.** ply 20 이상만 보면 자기 어댑터의 imitation 우위가 37~63% 줄어든다 (탈 37~40%, 스미슬로프 43~60%, 카르포프 63%). 1단계의 val 겹침(자기 train과 4~8%p 더 겹침)과 맞는다. 레퍼토리 기억이 우위의 일부다.
4. **카르포프가 가장 덜 갈라진다.** ply 20 이상의 기사 특이 몫이 11.4%로 가장 작다. top1 우위는 95% 구간이 0을 포함한다.
5. **regret은 어댑터에 따라 일정한 순서를 보인다.** 모든 val에서 탈 어댑터가 가장 높고 스미슬로프 어댑터가 가장 낮다. 예를 들어 탈 val에서는 0.0099, 0.0089, 0.0083이다. 어느 val에 두든 탈 어댑터의 정책이 베이스 기준 승률을 더 잃는 수에 확률을 더 싣는다는 뜻이다.

### 해석의 한계

- 모방 지표(기사의 실제 수를 맞히는 정도)만 봤다. 스타일 지문·혼동 행렬(제안서 6.3)이 아니다. 기풍이 분리됐다는 증거로 내세우지 않는다.
- regret의 순서(5번)가 기풍 차이(탈의 공격성 등)를 반영하는지는 알 수 없다. 베이스 승률 기준의 지표이고, 데이터 양·국면 분포·재개 이력의 차이도 겹쳐 있다.
- 세 어댑터는 데이터 양(국면 79k~96k)과 재개 이력이 다르다 (5절).
- val은 기사당 117~129국이다. 구간은 대국 단위 부트스트랩이라 대국 간 변동을 반영한다. 다만 기사의 시대별 레퍼토리 변화 같은 구조는 반영하지 못한다.
