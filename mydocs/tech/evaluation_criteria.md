## 1. 연구 목표와 주장

**연구 목표** (제안서 2장): 탐색에 의존하지 않는 Transformer 체스 모델에 세 기사(탈·카르포프·스미슬로프)의 기풍을 각각 주입하되 기력을 유지하고, 세 기풍의 차이를 정량적으로 비교한다.

목표를 주장 네 개로 나누어 따로 판정한다.

| 주장 | 내용 | 제안서 근거 | 틀렸다고 볼 상황 | 절 |
|---|---|---|---|---|
| **A 재현** | 어댑터가 베이스보다 해당 기사에 가까워졌다 | 2장, 6.1 | 기사 수 일치와 특성 분포가 베이스보다 나아지지 않는다 | 3 |
| **B 분리** | 세 어댑터의 기풍이 서로 다르다 | 2장, 6.3 | 어댑터 사이의 차이가 seed 사이의 차이와 구분되지 않는다 | 4 |
| **C 기력** | 기풍을 넣어도 기력이 유지된다 | 2장, 5.2, 6.1 | 대국 성적이나 독립 기준의 수 품질이 정해 둔 한계보다 떨어진다 | 5 |
| **D 인과** | 스타일 발현과 기력 유지가 우리 설계(스타일 항, 기력 항) 덕분이다 | 4.5, 6.1, 7.1 | 항을 빼거나 바꿔도 결과가 달라지지 않는다 | 6 |

**기사 범위**: 세 기사 모두 필수다. 제안서는 카르포프를 Phase 2 확장으로 두었지만 작업지시자 결정(2026-11-04)으로 필수에 넣었다 (9절).

**용어**

| 용어 | 뜻 |
|---|---|
| 베이스 | `base_model/136M.pt` (어댑터 없음) |
| 어댑터 | 베이스 위의 기사별 LoRA 어댑터. 학습 ID는 8절의 R1~R10, 기존 어댑터는 `runs/{player}_136M/` (seed 0, Task #5 수정 전 코드) |
| α = 0 어댑터 | 스타일 항 없이 모방 항과 기력 항으로만 학습한 어댑터 |
| 주 결과 어댑터 | α = α*, λ = 1로 학습한 어댑터 (α* 선택 규칙은 6절) |
| π | 어댑터 또는 베이스의 정책. temperature 0.02의 softmax (학습과 같은 설정) |

| f̃(s,a) | 수 a를 둔 뒤 국면의 스타일 특성 벡터를 정규화한 값 (정의는 특성 구현 이슈에서 확정) |
| w_p | 기사 p의 스타일 방향 벡터 |

## 2. 공통 규칙

### 2.1 표본 분리

- **평가 표본은 val뿐이다.** val은 기사별 고전 대국을 국 단위로 5% 나눈 것이다 (seed 0, 탈 117국 3,880국면 / 카르포프 122국 5,213국면 / 스미슬로프 129국 4,753국면).
- **w_p는 train으로만 추정한다.** val은 w_p 추정, 특성 정규화 통계, α 값 탐색에 쓰지 않는다. 그래서 학습 신호(w_p)를 만든 표본으로 스스로를 채점하지 않는다.
- 학습 중 val 평가는 기록용이며 체크포인트 선택(조기 종료)에 쓰지 않는다. 지금까지의 학습도 마지막 체크포인트를 그대로 썼다.
- 대국 평가(5절)와 AI 평가(3.4절)는 모델이 만든 대국을 쓰므로 val과 겹치지 않는다. 실제 기보가 필요한 경우(A9′ 검증 관문)에는 val 대국만 쓴다.

### 2.2 통계

- **집계 단위는 대국이다.** 같은 대국의 국면끼리는 독립이 아니므로, 신뢰구간은 대국 단위 부트스트랩으로 낸다.
- 부트스트랩: 10,000회, seed 0, 백분위 95% 구간 (Task #6과 같은 방식).
- **쌍대 비교**: 두 모델(예: 어댑터와 베이스)을 같은 국면에서 비교할 때는 대국을 다시 뽑은 뒤 두 모델의 차이를 계산한다. 두 모델의 구간을 따로 내서 겹침을 보지 않는다.
- "구간 하한 > 0"은 양측 95% 구간의 하한을 뜻한다 (단측 2.5% 수준).

### 2.3 다중 비교

- 주장의 통과 조건이 "필수 지표 × 기사 모두 통과"(2.5절)이면 **보정하지 않는다.** 모든 검정이 통과해야 주장을 채택하는 구조(intersection-union test)에서는 검정을 여러 번 해도 주장을 잘못 채택할 확률이 각 검정의 수준을 넘지 않기 때문이다.
- "기사 중 하나라도" 같은 합집합 주장을 할 때만 Holm 보정을 쓴다. 이 문서의 필수 판정에는 합집합 주장이 없다.
- 보조 지표는 보정 없이 보고하고 "탐색적"으로 표시한다.

### 2.4 구간 보고

- 국면 지표는 **전체**와 **ply 20 이상**을 함께 보고한다. Task #6에서 자기 어댑터 우위의 37~63%가 ply 20 미만(오프닝 레퍼토리)에서 나왔다.
- 판정에 쓰는 구간은 지표마다 정한다 (3절 이후 표의 "판정 구간").
- **"새 국면"**: ply 20 이상이면서 FEN(배치·차례·캐슬링·앙파상)이 세 기사 어느 train에도 없는 val 국면. Task #6 6절의 겹침 계산과 같은 FEN 키를 쓴다.

### 2.5 판정 결과와 기사 판정 규칙

지표와 주장의 판정은 다음 네 가지 중 하나다.

| 판정 | 조건 |
|---|---|
| **통과** | 모든 필수 지표가 세 기사 모두에서 통과 조건을 만족한다 |
| **부분 통과** | 실패한 지표는 없지만 일부 기사·지표만 통과 조건을 만족하고, 나머지는 판정 보류다 |
| **실패** | 필수 지표 하나 이상이 어느 기사에서 실패 조건을 만족한다 |
| **판정 보류** | 측정할 수 없거나(도구·학습 미비), 전제 조건이 깨졌거나(예: B3 잡음 바닥 실패), 구간이 통과와 실패 어느 쪽도 정하지 못한다 |

- 지표마다 통과 조건과 실패 조건을 따로 둔다. 둘 다 아니면 판정 보류다 (예: 구간이 0을 포함).
- 판정과 함께 **기사별 결과를 항상 표로 보고한다.** 주장이 통과하지 못해도 어느 기사에서 무엇이 됐는지 남긴다.
- 실패와 판정 보류도 연구 결과로 보고한다.

### 2.6 기력과 동반

스타일 지표(A, B)가 통과해도, 같은 어댑터의 C 판정이 통과가 아니면 "기풍 주입 성공"으로 보고하지 않는다 (제안서 6.1). 종합 규칙은 7절에 둔다.

### 2.7 기준 고정과 정정

- 이 문서의 값과 조건은 α > 0 어댑터의 결과를 보기 전에 고정한다. α = 0 어댑터의 결과는 이미 일부 알려져 있다 (Task #6).
- 고정 시점이 "후속"인 항목(3.3절 등)은 해당 이슈에서 값을 정하고, α > 0 결과를 보기 전에 이 문서에 정정으로 기록한다.
- 고정 뒤에 바꾸면 정정 이력에 날짜, 절, 내용, 이유를 적는다. 결과 보고에는 **바꾸기 전 기준의 판정도 함께** 적는다.

## 3. 주장 A: 재현

### 3.1 주장과 틀렸다고 볼 상황

- **주장**: 각 어댑터가 베이스보다 해당 기사의 수 선택에 가까워졌다.
- **틀렸다고 볼 상황**: val에서 기사 수 일치가 베이스보다 나아지지 않는다. 또는 모델이 둔 수의 특성 분포가 베이스보다 기사의 실제 분포에서 멀다.
- **평가 대상**: 주 결과 어댑터(α*), α = 0 어댑터(R1·R2·R8). α = 0 어댑터의 A 판정은 기준선으로 보고한다.
- **비교 대상**: 베이스. α > 0 어댑터는 α = 0 어댑터와의 차이도 함께 보고하지만 A 판정에는 쓰지 않는다. 이 차이는 D(6절)에서 쓴다.

### 3.2 채택 수단

| # | 수단 | 역할 | 필요 | 이유 |
|---|---|---|---|---|
| A1 | 수 일치 지표 (top1, imitation, top3) | **필수** | 즉시 | 제안서 6.1의 기본 지표. α = 0 기준선이 있다 |
| A2 | 새 국면의 수 일치 | **필수** | 즉시 | A1에서 오프닝 레퍼토리 기억을 뺀다 |
| A3 | 불일치 국면 쌍대 비교 | **필수** | 즉시 | 두 모델이 같은 수를 고르는 국면은 정보가 없다. 갈리는 국면만 보면 기사 쪽으로 옮겨 갔는지가 바로 보인다 |
| A5 | 특성 평균 거리 | **필수** | 특성 | 제안서 6.1 (i)의 "특성 평균 이동" |
| A6 | 특성 분포 거리 | **필수** | 특성 | 제안서 6.1 (ii)의 "분포 거리" |
| A4 | 국면 유형별 일치 | 보조 | 즉시 (복잡도 구간은 특성) | 어디서 기사에 가까워졌는지 설명한다. 칸마다 표본이 적어 판정에 쓰지 않는다 |
| A7 | 대국 통계 비교 | 보조 | 대국 | 상대와 대국 조건이 사람 대국과 달라 판정에 쓰지 않는다 |
| A8 | 기사 식별기 | 보조 | 대국 + 분류기 | B12와 같은 도구. 시대와 대국 조건을 학습할 위험이 있다 |
| A9′ | AI 평가자 블라인드 판별 | 보조 | 대국 + AI | 검증 관문 통과 시에만 채택 (3.4절) |
| A9 | 사람 블라인드 평가 | 선택 | 대국 + 사람 | 평가자를 확보하면 A9′와 같은 절차로 추가한다 |

### 3.3 지표 정의와 판정

공통 입력: 기사 p의 val 국면 s와 기사가 실제로 둔 수 a_p(s). 모델 m(어댑터 또는 베이스)의 정책 π_m(·|s), 1순위 수 â_m(s).

| # | 지표 | 계산 | 판정 구간 | 통과 | 실패 | 고정 시점 |
|---|---|---|---|---|---|---|
| A1 | top1 차이 | Δtop1 = mean[â_어댑터 = a_p] − mean[â_베이스 = a_p] (국면 평균, 대국 단위 쌍대 부트스트랩) | 전체 | 구간 하한 > 0 | 구간 상한 < 0 | 지금 |
| A1 | imitation 차이 | Δimit = mean[−log π_어댑터(a_p)] − mean[−log π_베이스(a_p)] | 전체 | 구간 상한 < 0 | 구간 하한 > 0 | 지금 |
| A2 | 새 국면 top1 차이 | A1의 Δtop1을 새 국면(2.4절)에서만 계산 | 새 국면 | 구간 하한 > 0 | 구간 상한 < 0 | 지금 |
| A3 | 불일치 국면 순 적중률 | 불일치 국면 D = {s : â_어댑터 ≠ â_베이스}. r = (n[â_어댑터 = a_p] − n[â_베이스 = a_p]) / \|D\| | 전체 | 구간 하한 > 0 | 구간 상한 < 0 | 지금 |
| A5 | 특성 평균 거리 감소 | μ_m = val 국면 평균 E_{π_m}[f̃(s,·)], μ_p = val 국면 평균 f̃(s, a_p). ΔA5 = ‖μ_어댑터 − μ_p‖ − ‖μ_베이스 − μ_p‖ | 전체 | 구간 상한 < 0 | 구간 하한 > 0 | 특성 정의 확정 시 (8.3절 4번) |
| A6 | 특성 분포 거리 감소 | 성분 k별 1차원 Wasserstein 거리 W_k(m) = W1({f̃_k(s, â_m)}, {f̃_k(s, a_p)}). ΔA6 = Σ_k W_k(어댑터) − Σ_k W_k(베이스) | 전체 | 구간 상한 < 0 | 구간 하한 > 0 | 특성 정의 확정 시 (8.3절 4번) |

**정의 보충**

- **A1**: 판정은 top1과 imitation 둘 다 통과해야 통과다. top3는 보고만 한다. ply 20 이상 값도 함께 보고한다 (2.4절).
- **A2**: 새 국면만 남기면 표본이 줄어든다. 개수는 Task #6 겹침 표로 어림한다: ply 20~39에서 자기 train과 겹치는 비율이 3.7~9.8%라, ply 20 이상 국면 대부분이 남는다. 실제 국면 수와 대국 수를 결과와 함께 보고한다.
- **A3**
  - r > 0이면 두 모델이 갈리는 국면에서 어댑터가 기사의 수를 더 자주 맞힌다는 뜻이다.
  - 국면이 독립이 아니므로 고전적인 McNemar 검정 대신 대국 단위 부트스트랩으로 판정한다. McNemar p값은 참고로만 보고한다.
  - 대표성을 확인하려고 \|D\| / 전체 국면 수와, D의 ply 분포를 전체 val의 ply 분포와 함께 보고한다.
- **A5**
  - 학습 목표인 w_p 방향 투영(w_p · μ)을 쓰지 않고, **기사의 실제 수의 특성 평균**까지의 거리로 잰다. 그래서 스타일 항의 목표를 다시 재는 순환을 줄인다.
  - 다만 α > 0 어댑터는 w_p 방향으로 밀리므로 투영도 보고한다. 투영은 판정에 쓰지 않는다.
  - 평균은 1순위 수가 아니라 π의 기대값으로 계산한다. 정책이 temperature 0.02라 1순위 수와 거의 같고, 값이 매끄럽다.
- **A6**
  - 성분마다 거리를 잰다. 성분별 값을 함께 보고해 어느 성분에서 가까워졌는지 보인다.
  - 1순위 수의 분포를 쓴다. 대국에서 실제로 두는 수에 가깝기 때문이다.
  - 성분 합을 쓰는 것은 f̃가 성분별 z-score로 같은 척도라는 전제에 기댄다. 정규화 방식이 정해지면 다시 확인한다.
- **A5·A6의 고정**: 특성 f(s,a)의 성분, 정규화 방식, 계산 비용(제안서의 미정 항목 1~4)이 특성 구현 이슈에서 정해진다. 그 뒤 α > 0 학습 전에 이 정의가 그대로 쓰일 수 있는지 확인하고, 바뀌면 정정으로 기록한다.

### 3.4 AI 평가자 블라인드 판별 (A9′, 보조)

사람 평가자 대신 LLM 에이전트가 섞인 기보를 보고 기사를 맞힌다. 제안서 6.2의 "인간 블라인드 평가"를 대신하지 못하므로 이름을 따로 쓰고 보조 증거로만 둔다.

**제시 형식: 국면 묶음**

한 문항은 대국 하나에서 뽑은 **평가 대상 쪽의 (FEN, 둔 수) 10쌍**이다. 조건은 다음과 같다.

- ply 20 이상의 국면에서 뽑는다
- 대국 순서대로 배열하되 상대의 수와 결과는 보이지 않는다
- 헤더(선수·대회·연도)는 없다

이 형식을 기본으로 하는 이유는 다음과 같다.

| 위험 | 이 형식의 효과 |
|---|---|
| 기보 암기 | 전체 기보가 아니라 중반 이후 조각이라 대국을 알아내기 어렵다 |
| 상대 단서 | 상대(사람 또는 엔진)의 수가 보이지 않는다 |
| 국면 추적 | FEN을 주므로 국면을 따라갈 필요가 없다 |

**절차**

1. **검증 관문**
   - 문항: 기사당 val 대국 30국, 합계 90문항
   - 과제: 세 기사 중 하나를 고르는 3지선다
   - 통과: 정답률의 Wilson 95% 구간 하한 > 1/3. 90문항이면 39문항(0.433) 이상 맞혀야 한다 (39문항의 하한 0.336, 38문항은 0.325)
   - 실패하면 A9′는 판정 보류로 두고 관문 결과를 보고한다
2. **기억 확인**: 관문 전에 문항마다 대국(선수, 대회, 상대)을 알아내는지 따로 묻는다. 알아낸 문항은 빼고 다른 대국으로 채운다. 뺀 수를 보고한다.
3. **본 평가**
   - 문항: 어댑터 기보, 베이스 기보, 실제 val 기보를 섞는다
   - 지표: 기사 p 어댑터의 문항이 p로 판별된 비율 − 베이스 문항이 p로 판별된 비율. 대국 단위 부트스트랩으로 구간을 낸다
   - 보조 증거로 채택하는 조건: 세 기사 모두 구간 하한 > 0
   - 기보는 C1·C2 대국 기보를 재사용한다. 주 결과 어댑터마다 30국, 베이스 30국이다 (5.6절)
4. **독립 실행**: 같은 문항을 3회 독립 실행한다. 판별은 3회 다수결로 정하고(셋이 모두 다르면 무응답), 실행 간 일치도(Fleiss κ)를 보고한다.
5. **기록**: 모델 ID, 프롬프트 원문, 온도, 실행 시각, 응답 원문을 저장한다.
6. **도구**: 엔진이나 python-chess 도구를 주지 않는다. 주면 특성 기반 분류기에 가까워져 고정관념 위험이 커진다.
7. **고정**: 프롬프트, 모델 ID, 문항 수는 실행 이슈에서 정하고 α > 0 결과 전에 정정으로 기록한다.

**한계**: 관문을 통과해도 LLM이 "탈 = 희생·공격" 같은 서술로 판단할 수 있다. 그래서 다음 두 결과를 함께 보고한다.

- 특성 층 결과(B8, B6)와의 상관
- 학습형 식별기(A8·B12) 결과와의 비교

### 4.3 특성 없는 층

공통 입력: 세 기사 val 국면의 합집합 S_val (368국, 13,846국면). 두 모델의 거리는 기사의 수와 관계없으므로 세 val을 합쳐 쓴다. 판정 구간은 전체이고, ply 20 이상 값도 보고한다.

#### B2 정책 거리 (B3의 입력)

- d(m₁, m₂) = S_val 평균 JS(π_m₁(·|s), π_m₂(·|s)). JS는 Jensen-Shannon 발산이며 밑은 2다(0~1).
- 1순위 불일치율 δ(m₁, m₂) = mean[â_m₁ ≠ â_m₂]도 함께 보고한다.

#### B3 잡음 바닥 (전제)

| 항목 | 정의 |
|---|---|
| 같은 기사 쌍 | (기존 seed 0, R1·R8·R2 seed 1). 기사마다 하나. 잡음 n_p = d(p seed 0, p seed 1) |
| 다른 기사 쌍 | 같은 코드의 seed 1 어댑터끼리 (R1–R8, R1–R2, R8–R2). 기사 쌍마다 하나 |
| 여유 | M(p, q) = d(p, q) − max(n_p, n_q) |
| 통과 | 세 기사 쌍 모두 M의 구간 하한 > 0 |
| 실패 | 어느 기사 쌍이든 M의 구간 상한 < 0 |
| 그 밖 | 판정 보류 |

- 구간은 S_val의 대국 단위 부트스트랩으로 낸다. 모든 모델을 같은 국면에서 평가하므로 쌍대다.
- 같은 기사 쌍 사이에는 seed 차이와 Task #5 결함 차이(데이터 순서, 국면 0.83~12.45%의 학습 횟수)가 함께 들어 있다. 그래서 잡음이 seed만의 잡음보다 크게 잡힐 수 있다. B에는 통과하기 더 어려운 쪽이다.
- 두 기사 중 큰 쪽 잡음(max)과 비교하는 것도 보수적인 선택이다.
- **α > 0 어댑터**: seed 반복이 없으므로 α = 0에서 잰 n_p를 그대로 쓴다. α > 0에서도 seed 분산이 같다는 가정이며, D8(6절)과 같다.
- **B3가 실패하면 B는 실패다** (4.1절의 틀렸다고 볼 상황). 판정 보류면 B 전체를 판정 보류로 두고, 나머지 지표는 보고만 한다.

#### B10 우도 혼동 행렬

| 항목 | 정의 |
|---|---|
| 점수 | 기사 p의 val 대국 g에 대해 L_m(g) = Σ_{s∈g, ply ≥ 20} log π_m(a_p(s)\|s), m은 세 어댑터 |
| 분류 | 대국 g를 argmax_m L_m(g)인 어댑터의 기사로 분류한다 |
| 3×3 행렬 | 행: 실제 기사, 열: 분류된 기사. 행마다 정규화한다 |
| 판정 지표 | 기사별 재현율(대각 값). 묶음 크기 k = 1 (대국 하나) |
| 통과 | 세 기사 모두 재현율의 구간 하한 > 1/3 |
| 실패 | 어느 기사든 재현율의 구간 상한 < 1/3 |
| 쌍별 판정 | 기사 쌍마다 두 어댑터만으로 2지선다를 해서, 두 기사 모두 재현율의 구간 하한 > 1/2이면 그 쌍은 통과다. 세 쌍 모두 통과해야 한다. 스미슬로프-카르포프(제안서가 가장 가깝다고 본 쌍)는 결과를 따로 강조해 보고한다 |

- **판정 구간이 ply 20 이상인 이유**: 제안서의 기풍은 수의 성격(복잡도, 희생 등)이다. Task #6에서 자기 어댑터 우위의 37~63%가 오프닝 레퍼토리에서 나왔다. 전체 구간 결과는 보고만 한다.
- **k = 1인 이유**: 대국 하나가 판정 단위가 되어 독립 표본 수가 가장 많다(기사당 117~129). k를 키우면 정확도는 오르지만 묶음 수가 줄어든다. k = 2, 5, 10의 결과도 보고한다. 묶음은 대국을 무작위로 나눠 만들고, 나누기를 1,000번 반복해 평균한다(seed 0).
- 구간은 대국 단위 부트스트랩으로 낸다.
- **어댑터의 전반적 우도 차이**: 어떤 어댑터가 모든 기사의 수에 우도가 높으면 대국이 그쪽으로 몰린다. 세 기사 모두의 재현율을 요구하므로 이 경우는 통과하지 못한다. 열 합계(어느 어댑터로 몰렸는지)도 보고한다.
- **한계**: 모방 지표의 연장이다. 어댑터가 실제 기사를 구별할 정보를 담고 있는지를 보이며, 어댑터가 대국에서 그렇게 두는지는 보이지 못한다. 그쪽은 특성 있는 층과 A9′가 맡는다.

### 4.4 특성 있는 층

특성 f(s,a)와 w_p, Stockfish가 있어야 한다. 특성 정의와 Stockfish 탐색 조건은 특성 구현 이슈에서 정한다.

**순환에 대해**: α > 0 어댑터는 w_p · f̃가 커지도록 학습된다. 그래서 특성 있는 층은 "스타일 항이 의도한 축에서 어댑터를 벌렸는가"를 판정하며, 그 자체로 실제 기사와 닮았다는 증거는 아니다. 실제 기사와 닮았는지는 A6(특성 분포 거리)과 B10이 판정한다. 순환을 줄이려고 다음을 지킨다.

- w_p와 정규화 통계는 train으로만 추정하고, 평가는 S_val에서 한다 (2.1절)
- α = 0 어댑터 값을 함께 보고한다. α = 0 어댑터는 w_p로 학습하지 않았다

#### B8 복잡도 쌍대 검정 (탈 대 스미슬로프)

| 항목 | 정의 |
|---|---|
| 국면 | S_val 중 탈 어댑터와 스미슬로프 어댑터의 1순위 수가 다른 국면 D_TS |
| 통계량 | Δc = D_TS 평균 [c(s, â_탈) − c(s, â_스미슬로프)]. c는 복잡도 성분이며 정규화 전 값이다 |
| 통과 | Δc의 구간 하한 > 0 (탈 어댑터가 더 복잡한 수를 고른다) |
| 실패 | Δc의 구간 상한 < 0 |

- 두 모델의 수가 같은 국면은 차이가 0이라 정보가 없으므로 뺀다. \|D_TS\|와 그 ply 분포를 보고한다.
- 같은 국면에서 비교하므로 국면 난이도 차이가 상쇄된다.
- **비용**: c는 국면당 Stockfish 탐색 2회(깊은 탐색, 얕은 탐색)다. D_TS의 국면마다 수 2개라서 대략 \|D_TS\| × 4회다. 불일치율을 30%로 가정하면 약 4,000국면, 1만 6천 회다(추정). 학습용 라벨링(합법수 전체)보다 훨씬 적다.
- **실제 기사 확인 (보고)**: 기사의 실제 수에서도 같은 방향인지 보고한다. 실제 기사는 같은 국면을 두지 않으므로, 각 기사 val에서 c(s, a_p) − E_{π_베이스}[c(s,·)]의 평균을 비교한다.

#### B6 지문 점수 혼동 행렬

| 항목 | 정의 |
|---|---|
| 점수 | 모델 m이 국면 s에서 고른 수의 기사 q 점수: z_q(s) = w_q · (f̃(s, â_m) − E_{π_베이스}[f̃(s,·)]) |
| 묶음 | S_val에서 대국 단위로 뽑은 국면 k개. 묶음 점수 Z_q = Σ z_q(s) |
| 분류 | 모델 m의 묶음을 argmax_q Z_q인 기사로 분류한다 |
| 3×3 행렬 | 행: 어댑터의 기사, 열: 분류된 기사 |
| 통과 | 세 어댑터 모두 대각 재현율의 구간 하한 > 1/3 |
| 실패 | 어느 어댑터든 재현율의 구간 상한 < 1/3 |

- 베이스 기대값을 빼서 국면 자체의 특성(예: 원래 복잡한 국면)을 상쇄한다.
- **판정 k의 고정**: 특성 구현 뒤에 α = 0 어댑터로 k = 10, 25, 50, 100의 재현율 곡선을 잰다. 그다음 α > 0 학습 전에 판정 k를 정해 정정으로 기록한다. 기준은 "α = 0에서 재현율 구간 폭이 0.1 이하가 되는 가장 작은 k"를 제안한다.
- **제안서와 다른 점**: 제안서는 "가장 가까운 지문으로 분류"라고 했다. 모델 지문 ŵ를 묶음마다 회귀로 추정하면 작은 묶음에서 불안정하므로, w_q 점수의 합으로 분류한다.

### 4.5 카르포프의 방향 (B4)

**문제**: 카르포프의 기풍("견고·질식")은 제안서 특성 4성분(c, Δmaterial, kingAttack, simplify)에 대응하는 성분이 없다. 그래서 B8 같은 성분 단위의 방향 검정을 할 수 없다.

**판정 수단**: 제안서 6.3의 예측 "탈-스미슬로프가 가장 멀고, 카르포프가 그 사이"를 모델 지문으로 검정한다.

| 항목 | 정의 |
|---|---|
| 모델 지문 | ŵ_m: w_p와 같은 회귀 절차로, 기사의 수 대신 모델 m의 1순위 수를 써서 S_val에서 추정한다 |
| 거리 | d(m₁, m₂) = 1 − cos(ŵ_m₁, ŵ_m₂) |
| 통계량 | G = d(탈, 스미슬로프) − max(d(탈, 카르포프), d(카르포프, 스미슬로프)) |
| 통과 | G의 구간 하한 > 0 |
| 실패 | G의 구간 상한 < 0 |

- 구간은 S_val 대국 단위 부트스트랩으로 낸다. 반복마다 ŵ를 다시 추정한다.
- **데이터 전제**: 실제 기사 지문 w_p(train)에서도 같은 순서인지 먼저 확인해 보고한다. 실제 지문이 이 순서가 아니면, 제안서의 예측은 데이터에서부터 성립하지 않는 것이다. 이 경우 B4는 판정 보류로 두고, 실제 순서와 모델 순서가 맞는지만 보고한다.
- **특성 구현 이슈에 넘기는 요구 사항 (선택)**: 카르포프의 "질식"을 직접 재는 성분(예: 상대 합법수의 감소)을 추가하는 것을 검토한다. 추가하면 B8과 같은 형식의 카르포프 쌍대 검정을 보조로 둔다. 추가 여부는 특성 이슈에서 정하며, B의 필수 판정은 B4로 한다.

## 5. 주장 C: 기력

### 5.1 주장과 틀렸다고 볼 상황

- **주장**: 기풍을 넣어도 기력이 유지된다. 이 주장은 비열등성 주장이다. 베이스보다 강해질 필요는 없고, 정해 둔 한계보다 약해지지 않으면 된다.
- **틀렸다고 볼 상황**: 대국 성적이나 독립 기준(Stockfish)의 수 품질이 한계보다 떨어진다.
- **평가 대상**: 주 결과 어댑터(α*)의 판정이 필수다. α = 0 어댑터(R1·R2·R8), 다른 α 어댑터, R7(λ = 0)도 같은 조건으로 재며, 이 값들은 D(6절)에서 쓴다.
- **비교 대상**: 베이스.

### 5.4 지표 정의와 판정

**Elo 집계 (C1·C2)**

- 짝(오프닝 하나, 2국)의 점수 합 0~2를 단위로 쓴다.
- 짝을 부트스트랩(10,000회, seed 0)해서 점수율 s를 구하고 Elo로 바꾼다: Elo = −400·log₁₀(1/s − 1). 구간은 백분위 95%다.
- 짝 단위로 묶어 오프닝 효과로 인한 분산을 줄인다 (Fishtest의 오각 분포 방식과 같은 생각).

**허용 한계**

- 대국 지표의 비열등 한계는 **−50 Elo**다. 점수율로는 0.429다.

**C2 Stockfish 상대**

- 강도 제한: 탐색 노드 수를 고정한다. 시간 제한은 장비에 따라 강도가 달라지므로 쓰지 않는다. 설정은 `Threads = 1`, `Hash` 고정이다.
- **노드 수 보정**: α > 0 결과 전에 베이스 136M을 노드 수 후보 몇 개와 100국씩 둔다. 베이스 점수율이 0.35~0.65에 드는 노드 수를 골라 정정으로 기록한다. 점수율이 0이나 1에 가까우면 차이가 구분되지 않기 때문이다.
- C2 차이의 구간은 같은 오프닝 짝끼리 쌍대로 부트스트랩한다.
- Stockfish 버전은 대국 실행기 이슈에서 하나로 고정하고 모든 측정에 같은 버전을 쓴다.

**C3 베이스 기준 regret**

- 학습 기력 항의 허용 밴드 τ = 0.02(베이스 기준 승률 2%p)를 한계로 쓴다. 어댑터의 1순위 수가 평균적으로 밴드 안에 있어야 한다.
- 단독으로는 판정하지 않는다. C의 통과에는 C1, C2, C4가 함께 필요하다.
- regret, band_violation, strength도 보고한다. α = 0 기준선은 regret_top1 0.0027~0.0029다 (10절).

**C4 Stockfish 기준 수 품질**

- 대국 한 판이 약 80 ply이고 136M 응답이 수당 41.5~56.9 ms(Task #7 실측 중앙값)라면, 모델끼리 대국은 판당 약 4~5초다. Stockfish 대국은 SF 차례의 시간이 더해진다.
- 합계는 대략 **10~13시간**이다 (추정). 실측 응답 시간은 앱 경유 값이므로 대국 실행기에서 다시 잰다.
- A9′ 문항은 이 기보에서 뽑는다. 주 결과 어댑터마다 30국, 베이스 30국이다 (3.4절).
- 실행 장소는 GPU 서버다. Stockfish를 학습용 환경과 같은 docker 이미지에 넣을지는 8절의 요구 사항으로 둔다.

### 5.7 판정 요약

| 판정 | 조건 |
|---|---|
| 통과 | C1, C2, C3, C4가 세 기사의 주 결과 어댑터 모두에서 통과 |
| 실패 | 하나라도 어느 기사에서 실패 |
| 판정 보류 | 그 밖. 대국 수를 결과를 본 뒤 늘리지 않는다 (사후 추가는 정정 절차를 따르고 원래 판정을 함께 보고) |

- C1은 자가 대국이라 차이가 과장되거나 줄 수 있다. C1과 C2의 방향이 다르면 결과를 함께 보고하고, 판정은 위 규칙대로 둘 다 통과해야 통과다.

### 5.8 α = 0 기준선

- C3: regret_top1 0.0027~0.0029로 τ = 0.02보다 한 자릿수 작다. regret과 band_violation은 베이스보다 좋다 (10절).
- C1, C2, C4는 아직 재지 않았다. Task #7 실기 대국(사용자 대 탈 136M 어댑터 1국)은 표본이 하나라 기준선으로 쓰지 않는다.

## 6. 주장 D: 인과

### 6.1 주장과 틀렸다고 볼 상황

- **주장**: 스타일 발현은 스타일 항 덕분이고, 기력 유지는 기력 항 덕분이다.
- **틀렸다고 볼 상황**: α를 키워도 스타일 발현이 늘지 않는다. 또는 기력 항을 빼도(λ = 0) 기력이 같다. 또는 특성 이동이 w_p 방향을 따르지 않는다.
- **비교군**: 현재 코드로 학습한 어댑터(R1~R10)끼리만 비교한다. 기존 어댑터(Task #5 수정 전 코드)는 B3의 잡음 바닥 쌍에만 쓴다.

### 6.2 α 값과 α*

**α* 사전 고정**: 주 결과 어댑터는 **α* = a₂**(큰 쪽)로 미리 정한다. a₁은 곡선의 중간 점이다.

결과를 보고 α*를 고르지 않는 이유는 다음과 같다.

- val의 A·B 지표로 고르면 같은 val로 판정하므로 선택 편향이 생긴다 (평가 표본이 val뿐이다, 2.1절).
- "C를 통과하는 가장 큰 α"처럼 C로 고르면 C 판정이 유리해진다.
- a₂가 C를 통과하지 못하면 "a₂에서 기력 유지 실패"로 보고한다. 이 경우 a₁의 결과는 탐색적으로만 보고한다.

**a₁, a₂를 정하는 규칙**: 학습 시작 시점의 기울기 크기 비로 정한다. 방법은 다음과 같다.

1. 베이스에 새 LoRA를 붙인 상태에서 train 배치 50개로 ‖∇L_imit‖와 ‖∇L_style‖의 평균을 잰다.
2. α = r · ‖∇L_imit‖ / ‖∇L_style‖로 정한다. r은 a₁에 0.3, a₂에 1.0이다.
3. 기사마다 따로 잰다. 다만 제안서대로 α를 세 기사가 공유하도록, 세 기사 값의 중앙값을 쓴다.

측정은 특성 구현 이슈에서 한다. α > 0 학습 전에 값을 정정으로 기록한다. r 값은 기울기 기준으로 "모방의 30%"와 "모방과 같은 크기"를 뜻한다. 근거가 있는 값이 아니라 스윕 범위를 정하는 선택이다.

### 6.3 스타일 발현과 기력의 척도 (D 공통)

| 척도 | 정의 | 이유 |
|---|---|---|
| 스타일 발현 S_p(m) | S_val 평균 w_p · (f̃(s, â_m) − E_{π_베이스}[f̃(s,·)]). 기사 p 어댑터 m의 자기 지문 점수다 (B6 점수 z_p의 평균) | 스타일 항이 키우려는 양을 그대로 잰다. D는 "항이 의도대로 작동했는가"를 묻는 주장이므로 이 순환은 의도한 것이다 |
| 기력 K(m) | C4의 Stockfish 기준 평균 승률 손실 (S_val, 1순위 수) | 같은 국면에서 쌍대로 비교할 수 있어 대국 Elo보다 검정력이 높다. C1 Elo는 함께 보고한다 |

### 6.4 채택 수단과 판정

| # | 수단 | 기사 | 통과 | 실패 |
|---|---|---|---|---|
| D2 | α 용량 반응 | 세 기사 | S_p(a₁) − S_p(0) > 0이고 S_p(a₂) − S_p(a₁) > 0. 둘 다 구간 하한 > 0 | 어느 기사든 S_p(a₂) − S_p(0)의 구간 상한 < 0 |
| D1 | 기력 항 ablation | 탈 | K(R7, λ = 0) − K(탈 a₂, λ = 1)의 구간 하한 > 0 (기력 항이 있을 때 손실이 작다) | 구간 상한 < 0 |
| D3 | 같은 스타일 발현에서의 기력 비교 | 탈 | λ = 1 곡선의 K를 S(R7)에서 선형 보간한 값을 K̂라 한다. K(R7) − K̂의 구간 하한 > 0 | 구간 상한 < 0 |
| D6 | 방향 통제 분석 | 세 기사 | cos(δ_p, w_p)의 구간 하한이 무작위 방향 코사인 분포의 95번째 백분위수보다 크다 | cos(δ_p, w_p)의 구간 상한이 무작위 분포의 중앙값보다 작다 |
| D8 | seed 변동 대비 효과 | 세 기사 (D1은 탈) | D2의 인접 차이와 D1의 차이가 모두 같은 지표의 seed 차이보다 크다 | 효과가 seed 차이보다 작다 |

**정의 보충**

- **D2**
  - 구간은 S_val 대국 단위 쌍대 부트스트랩으로 낸다. 같은 국면에서 세 모델을 평가하므로 쌍대다.
  - 세 기사의 (S_p, K, C1 Elo) 곡선을 한 그림에 겹쳐 보고한다 (제안서 4.5의 트레이드오프 곡선).
- **D1**
  - α를 a₂로 같게 두고 λ만 바꾼 비교다.
  - band_violation과 C1 Elo 차이도 보고한다. Elo 차이는 구간이 넓어 판정에 쓰지 않는다 (두 어댑터 각 ±21~31).
- **D3**
  - S(R7)가 λ = 1 곡선의 S 범위 [S(0), S(a₂)] 밖이면 판정 보류다. 보간할 수 없기 때문이다.
  - 부트스트랩 반복마다 곡선과 R7을 같은 표본으로 다시 계산한다.
- **D6**
  - δ_p = μ(a₂) − μ(0)이다. μ(m) = S_val 평균 E_{π_m}[f̃(s,·)]이고, a₂와 0은 같은 기사의 λ = 1 어댑터다.
  - 무작위 방향은 특성 차원의 단위 벡터 10,000개다(seed 0).
  - α = 0 어댑터의 이동(μ(0) − μ(베이스))과 w_p의 코사인도 보고한다. 모방만으로도 w_p 쪽으로 움직였는지 보기 위해서다.
  - **한계**: 스타일 항의 기울기가 w_p 방향이므로 통과는 예상되는 결과에 가깝다. D6이 실패하면 기력 항이나 다른 손실이 스타일 이동을 막고 있다는 뜻이라, 실패 쪽에 정보가 많다. 무작위 방향으로 학습한 통제군보다 약한 증거다.
- **D8**
  - seed 차이는 기사마다 하나뿐이다: (기존 seed 0, 새 seed 1)의 α = 0 쌍. 그래서 분산은 추정할 수 없다. 관측된 차이 세 개의 최댓값과 비교한다.
  - 이 차이에는 Task #5 결함 차이도 들어 있어 크게 잡힐 수 있다. D에는 통과하기 어려운 쪽이다.
  - α > 0에서도 seed 변동이 α = 0과 같다고 가정한다. 이 가정은 검증하지 않는다.

### 6.5 기사 범위의 예외

D1·D3는 탈에서만 판정한다 (학습 설계 R7, 8절). 2.5절의 "세 기사 모두" 규칙에서 D1·D3는 예외이며, D의 판정 결과에 "λ 비교는 탈 한 기사"라고 함께 적는다. 탈을 고른 이유는 희생 성향(Δmaterial)이 있어 스타일과 기력이 가장 부딪히기 쉬운 기사이기 때문이다.

### 6.6 학습하지 않는 수단

D4(λ, τ 용량 반응), D5(LoRA 배율 보간), D7(기사 라벨 통제), 무작위 방향 학습 통제군은 이번 기준의 판정에 쓰지 않는다. D5는 재학습이 없어 실행 이슈에서 보조로 추가할 수 있다.

### 6.7 판정 요약

| 판정 | 조건 |
|---|---|
| 통과 | D2, D6, D8이 세 기사 모두 통과하고, D1, D3가 탈에서 통과 |
| 실패 | 하나라도 실패 |
| 판정 보류 | 그 밖 (D3 보간 불가 포함) |

## 7. 종합 판정 규칙

### 7.1 연구 목표 판정

연구 목표는 "기풍을 주입하되 기력을 유지하고, 세 기풍의 차이를 정량 비교한다"이다. 판정은 주 결과 어댑터(α* = a₂)로 한다.

| 결론 | 조건 |
|---|---|
| **목표 달성** | A 통과, B 통과, C 통과 |
| **목표 달성 (설계 효과 포함)** | 위에 더해 D 통과 |
| **부분 달성: 특성 축 미확인** | A·C 통과, B 부분 통과 (특성 없는 층만 통과). "기사별로 갈라졌고 실제 기사 차이와 맞다"까지 주장한다 |
| **부분 달성: 재현만** | A·C 통과, B 실패 또는 판정 보류 |
| **기력 유지 실패** | C 실패. A·B 결과는 보고하되 "기풍 주입 성공"이라고 쓰지 않는다 (2.6절) |
| **재현 실패** | A 실패 |
| **판정 보류** | A 또는 C가 판정 보류 |

- 여러 결론에 해당하면 표에서 위쪽에 있는 실패 쪽 결론을 우선한다. 예를 들어 A 실패이면서 C 실패면 둘 다 적는다.
- D는 목표 달성 여부를 바꾸지 않는다. D는 "그 결과가 우리 설계 덕분인가"라는 추가 주장이다.

### 7.2 보고 형식

- 결론 한 줄, 주장 A~D의 판정, 기사별 지표 표(통과·실패·보류 표시)를 함께 보고한다.
- α = 0 어댑터(R1·R2·R8)의 A·B·C 결과는 "모방만으로 얻은 기준선"으로 나란히 보고한다.
- 정정이 있었으면 바꾸기 전 기준의 판정도 적는다 (2.7절).
- 실패와 판정 보류도 결과다. 어느 지표가 왜 실패했는지 적는다.
