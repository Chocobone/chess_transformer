## 짚어 둘 점

1. **특성 없는 층 B는 판정 보류다.** 실패는 아니다. 보류를 풀려면 기준 정정(판정 구간, k, 쌍별 조건)이나 val 확대가 필요하다. 이 타스크의 범위 밖이고, 정정한다면 α > 0 결과가 나오기 전에 해야 한다 (작업지시자 결정 사항)
2. **구별 신호의 상당 부분이 오프닝에 있다.** 전체 ply로는 쌍별까지 통과한다. 특성 있는 층과 α > 0 학습에서 ply ≥ 20 신호가 커지는지가 다음 확인 대상이다
3. **카르포프가 가장 약하다.** B10, 쌍별, B1 기사 특이 몫(ply ≥ 20에서 12.1%), ply ≥ 20 Δtop3에서 모두 그렇다
4. **seed 잡음은 작다.** n_p는 d의 약 1/15이고, 학습 GPU 기종 차이도 잡음을 눈에 띄게 키우지 않았다. 다만 판정이 경계 근처인 지표(A2, B10)는 seed에 따라 통과와 보류가 바뀐다
5. **현재 코드의 α = 0 기준선은 Task #6과 거의 같다** (8.1절)
6. **구현 계획서의 `base.json`은 없다.** 베이스 대조는 각 모델 json의 `baseline` 항목에 있다 (4단계 보고서)
