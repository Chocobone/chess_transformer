### 확인

- 마지막 `eval`의 step(7455)이 `config.json`의 `total_steps`(7455)와 같다.
- `train` 줄 373개의 step이 20, 40, …, 7440, 7455로 빠짐·겹침이 없다 (재개 지점 포함).
- 저장된 `adapter.pt`를 새로 올린 베이스에 `load_adapter`로 붙여 val 전체를 다시 평가한 값이 마지막 `eval`의 7개 지표와 모두 같다 (차이 0).
- 재개 기능을 넣기 전 코드로 돌린 2차 실행(`runs/tal_136M_failed_0311/`, step 4000 평가 직후 중단)의 기록 205줄 전체가 이 실행의 같은 구간과 같다 (시간·메모리 값 제외).
