# Task #6 테스트 결과: 세 기사 136M 어댑터 교차 평가

- 날짜: 2026-10-15
- 실행 위치: 로컬 개발 컨테이너(WSL2), RTX 4070 Ti 12GB
- 코드: `local/task6` (소스는 Task #5 수정 후 `51adcc2`와 같음). 평가 스크립트는 스크래치패드(`cross_eval.py`, 저장소 밖)
- 베이스: `base_model/136M.pt`, 어댑터: `runs/{tal,karpov,smyslov}_136M/adapter.pt`
- 단위: GiB = MiB / 1024

## 실행

```bash
# run_cross.sh: 어댑터마다 새 프로세스 하나, 그 안에서 탈·카르포프·스미슬로프 val을 차례로 평가
for a in tal karpov smyslov; do
  PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True python -u cross_eval.py $a
done
# GPU 사용량은 5초마다 runs/logs/cross_eval_136M_gpu.log에 기록
```

- `cross_eval.py`는 `src.train.train.evaluate`의 계산을 그대로 옮기고 국면별 값을 함께 남긴다. 합계는 `evaluate`와 같은 방식(묶음마다 `.sum().item()`)으로 낸다. 설정은 `Objective()` 기본값(temperature 0.02, τ 0.02), 합법수 256개씩, float32, val 배치 32, `shuffle=False`다.
- 결과: `runs/cross_eval_136M/{adapter}_on_{val}.json`(지표, 시간, 메모리), `.npz`(국면별 값). 기준선의 국면별 값은 `base_on_{val}.*`이다 (CPU, 캐시의 베이스 q). 모두 git 제외.
- 표준 출력: `runs/logs/cross_eval_136M.log` (git 제외)
