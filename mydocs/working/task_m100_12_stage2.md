### `src/eval/judge.py` (새 파일) — 판정과 보고

```
python -m src.eval.judge runs/gpu/dump --out runs/gpu/judge
  → results.json (모든 값·구간·판정), report.md (표)
```

- 기본 역할: 판정 대상 `R1,R8,R2`, 잡음 바닥 `R1s0,R8s0,R2s0` (탈, 카르포프, 스미슬로프 순). `--main`, `--seed0`로 바꿀 수 있다 (α > 0 평가에서 다시 쓴다)
- 판정하지 않고 멈추는 경우(종료 코드 2): 모델의 학습 기록 대조(`{모델 ID}.json`)가 통과가 아니거나, 덤프의 기사가 자리와 다를 때
- 판정 묶음

| 항목 | 규칙 |
|---|---|
| A1 | top1·imitation 둘 다 통과면 통과, 하나라도 실패면 실패 |
| 특성 없는 A | 실패가 있으면 실패. A1~A3가 모두 통과면 "부분 통과 (A5·A6 판정 보류)". 통과와 보류가 섞이면 "부분 통과 (A5·A6와 일부 지표 판정 보류)". 통과가 하나도 없으면 판정 보류 (2.5·3.5절) |
| B10 | 3지선다 실패면 실패. 3지선다와 쌍별 모두 통과면 통과. 그 밖 판정 보류 |
| 특성 없는 층 B | B3 또는 B10 실패면 실패, 둘 다 통과면 통과, 그 밖 판정 보류 (4.7절) |
| C3 | 기사별 판정, "단독 판정 불가"로 표시 |

- seed 0 어댑터의 A·C3·B10(3지선다) 값은 참고로 함께 낸다. B10은 전체 ply 값도 보고로 낸다

## 결과를 보기 전에 정한 추가 해석 (2026-11-12 승인)

구현 계획서의 해석 1~7 외에, 구현하면서 정해야 했던 것이 넷 있다.

8. **B10에서 ply ≥ 20 국면이 없는 대국은 뺀다.** 점수 L_m(g)가 모든 어댑터에서 0이라 정보가 없다. 동률 규칙(해석 2)대로 오답으로 세는 대신 빼고, 뺀 대국 수를 보고한다
9. **분모가 0인 부트스트랩 반복은 뺀다.** 예를 들어 A2에서 새 국면이 있는 대국을 하나도 뽑지 않은 반복이다. 실제 val(기사당 117~129국)에서는 거의 생기지 않는다. 모든 반복이 정의되지 않으면 구간이 NaN이고 판정은 보류가 된다
10. **B10 쌍별 판정에는 실패 조건이 없다.** 기준 문서는 쌍별 통과 조건만 둔다. 그래서 쌍별이 통과하지 못하면 판정 보류로 두고, B10 실패는 3지선다 실패로만 낸다 (4.7절의 "B10 실패")
11. **특성 없는 A의 표기**: 위 판정 묶음 표의 규칙이다. 2.5절 "부분 통과"(실패 없음, 일부 통과, 나머지 보류)를 따른다
