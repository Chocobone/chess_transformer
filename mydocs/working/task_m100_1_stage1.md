# Task #1 단계1 완료 보고서: PGN 전처리 파이프라인

## 수행 내용

세 기사의 PGN을 "대상 기사가 둘 차례인 국면" 단위 데이터셋으로 바꾸는 전처리 CLI를 작성하고,
세 기사 실제 기보에 실행했다. 코드는 하나이며 기사 차이는 `src/players.py`의 PGN 경로와 이름 접두어뿐이다.

```
python -m src.data.preprocess --player tal [--include-fast] [--val-ratio 0.05] [--seed 0] [--out-dir DIR]
```

출력은 `data/processed/{player}/`의 `train.jsonl`, `val.jsonl`, `stats.json`이다 (git 제외 대상).

## 발견 사항

1. **0단계 `.gitignore` 오류 수정**: `data/` 규칙이 `src/data/`까지 무시하고 있어, 0단계 커밋(`b81dcb3`)에 `src/data/__init__.py`가 빠져 있었다. 규칙을 `/data/`처럼 루트로 한정해 고쳤고, 빠진 파일은 이번 단계 커밋에 포함된다.
2. **카르포프 PGN은 UTF-8이 아니다**: 0xA0 바이트가 있어 UTF-8로 읽으면 실패한다. 세 파일 모두 `latin-1`로 읽도록 했다. 수와 태그는 ASCII라 결과에 영향이 없다.
3. **이벤트 필터 규칙을 계획서보다 넓혔다**: 계획서의 키워드로는 카르포프의 속기·다면기 판 81판이 빠져나갔다. 실제 이벤트명을 조사해 다음을 추가했다. 탈·스미슬로프는 추가 규칙으로 달라진 판이 없다.
   - `sim1` (Koszalin sim1, 15판), 단어 `rap` (Varna rap m 등 16판)
   - 제한 시간 표기 `g/25`, `30'` 등 (Budapest m 30', Match g/25 등 36판)
   - `tiebreak`/`TB` (6판), `exh3` (2판)
   - 컴퓨터 보조 대국 `Advanced`, `Man+Comp` (8판) — 기사 혼자 고른 수가 아니므로 제외
4. **이름만으로는 판단할 수 없어 남겨 둔 이벤트 (2026-10-07 작업지시자 결정: 제외하지 않고 포함)**: 아래는 이벤트명에 표기가 없어 classical로 분류되었지만 실제로는 속기였을 가능성이 있다. 모두 카르포프의 판이다.
   - `Karpov Trophy` 계열 (2nd/4th/5th Prelim·KO·본선, 6th Match — 합계 59판)
   - `Eurotel Trophy` (12판), `Trophee CCAS GpB Playoff` (4판), `CEZ Trophy Match` (2판)
   - `Match` (15판), `Hou vs Karpov Match 2018` (6판), `Snowdrops vs Old-hands` (8판)
   - `Dortmund man-comp` (1판) — 컴퓨터를 상대로 둔 판이며 수는 카르포프가 직접 둔 것이라 남겼다
5. **계획서와 다르게 걸러진 판**: `Classical Exhibition Match` (카르포프 2판)는 `exhibition` 규칙에 걸려 제외된다. 시범 대국 기본 제외 결정을 그대로 따랐다.
6. **이름 표기**: 스미슬로프도 `Smyslov,V` 표기가 20판 있었다 (수행 계획서에는 1종으로 기재). 접두어 `Smyslov,`가 둘 다 잡는다. 카르포프에는 백·흑이 모두 `Karpov, Anatoly`로 적힌 판이 1판(`Voronezh simul`) 있어 건너뛴다.
7. **비합법 수로 파싱이 실패한 판은 없다.** 수가 하나도 없는 판이 4판 있어 건너뛴다.
8. **중복 국면**: 서로 다른 FEN은 전체 국면의 약 83%다. 나머지는 초반 정석 국면의 반복이며, 기사의 실제 빈도를 반영하므로 그대로 둔다.
9. **`--include-fast`의 출력 위치**: 기본 실행과 같은 폴더에 덮어쓴다. 어떤 설정으로 만든 데이터인지는 `stats.json`의 `include_fast`에 남는다.
