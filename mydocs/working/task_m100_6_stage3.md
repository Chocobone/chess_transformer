## 1. GPU 사용량 단위 정정

### 방법

1. Task #2~#4의 계획서·보고서·테스트 결과·단계 보고서, 오늘할일(20261012~14), 가이드에서 "X GiB" 값을 모두 뽑았다. PyTorch 값(`max_memory_gib`, 예약, 할당)은 뺐다.
2. 값마다 GPU 기록(`runs/logs/*gpu*.log`, `gpu_mem_*.log`의 MiB) 전체와 대조했다. 표기 자리수의 반올림 범위 안에서 ÷1000으로만 맞는지, ÷1024로만 맞는지, 둘 다 맞는지, 로그가 없는지를 판정했다 (스크래치패드 `gib_audit.py`).
3. 판정 결과를 줄마다 원문으로 다시 확인해 실제 정정 대상을 골랐다. 자동 판정에서 ÷1000으로 걸렸지만 실제로는 맞는 값이 8곳 있었다.
   - 기준값 "11.8 GiB(12,083 MiB)" 5곳
   - 카드 용량 "12.0 GiB"
   - "3,512 MiB(3.43 GiB)"
   - 데스크톱 "1.2 GiB"(1,214 MiB)
4. 정정은 스크래치패드 `correct_gib.py`로 넣었다. 원문이 파일에 정확히 한 번 나올 때만 바꾼다. 정정 표시를 걷어 내면 바뀐 32줄 모두 원문과 같음을 확인했다.

## 2. 실행 가이드 갱신 (`mydocs/manual/training_guide.md`)
