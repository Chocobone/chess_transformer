## 주요 결정 제안 (승인 요청)

### 1. α* 사전 고정과 a₁, a₂ 규칙 (6.2절)

- **α* = a₂(큰 쪽)로 미리 정한다.** 결과로 고르지 않는다.
  - val 지표로 고르면 같은 val로 판정하게 된다. 평가 표본이 val뿐이다.
  - "C를 통과하는 가장 큰 α"처럼 C로 고르면 C 판정이 유리해진다.
- **a₁, a₂ 규칙**: 학습 시작 시점의 기울기 크기 비로 정한다. α = r · ‖∇L_imit‖ / ‖∇L_style‖이고, r은 a₁에 0.3, a₂에 1.0이다. 세 기사 값의 중앙값을 공유한다.
- r 값은 근거에서 나온 값이 아니라 스윕 범위를 정하는 선택이다. 측정은 특성 이슈에서 하고, α > 0 학습 전에 기록한다.

### 2. D의 척도와 판정 (6.3~6.4절)

**척도**

- **스타일 발현**: 자기 지문 점수의 평균이다. 스타일 항이 키우려는 양이라 순환이 있지만, D는 "항이 의도대로 작동했는가"를 묻는 주장이라 의도한 순환이다.
- **기력**: C4의 Stockfish 손실이다. 같은 국면에서 쌍대로 비교하므로 Elo보다 검정력이 높다. Elo는 보고만 한다.

**판정**

| # | 기사 | 통과 조건 |
|---|---|---|
| D2 | 세 기사 | 스타일 발현이 α = 0 → a₁ → a₂로 단조 증가 (인접 차이 구간 하한 > 0) |
| D1 | 탈 | λ = 0의 손실이 λ = 1보다 크다 (구간 하한 > 0) |
| D3 | 탈 | 같은 스타일 발현에서 λ = 0의 손실이 λ = 1 곡선보다 크다. 보간이 안 되면 판정 보류 |
| D6 | 세 기사 | 특성 이동 방향과 w_p의 코사인이 무작위 방향의 95번째 백분위수보다 크다 |
| D8 | 세 기사 | 효과가 관측된 seed 차이(기사당 1개) 최댓값보다 크다 |

### 3. 종합 판정 규칙 (7.1절)

| 결론 | 조건 |
|---|---|
| 목표 달성 | A, B, C 통과 |
| 목표 달성 (설계 효과 포함) | 위 + D 통과 |
| 부분 달성: 특성 축 미확인 | A·C 통과, B는 특성 없는 층만 통과 |
| 부분 달성: 재현만 | A·C 통과, B 실패 또는 보류 |
| 기력 유지 실패 | C 실패 ("기풍 주입 성공"이라고 쓰지 않는다) |
| 재현 실패 | A 실패 |
| 판정 보류 | A 또는 C 보류 |

## 발견 사항

1. **α*를 결과로 고르면 어떤 방식이든 편향이 생긴다.** 평가 표본이 val뿐이라 A·B로 고르면 A·B 판정이, C로 고르면 C 판정이 유리해진다. 그래서 a₂로 미리 고정했다. a₂가 기력 유지에 실패할 위험은 결과로 보고한다.
2. **D6은 실패 쪽에 정보가 많다.** 스타일 항의 기울기가 w_p 방향이라 통과는 예상되는 결과에 가깝다. 실패하면 다른 손실이 스타일 이동을 막고 있다는 뜻이다. 무작위 방향으로 학습한 통제군보다 약한 증거라는 점을 6.4절에 적었다.
3. **D8의 seed 차이는 기사당 하나뿐이다.** 분산을 추정할 수 없어 관측값 세 개의 최댓값과 비교한다. α > 0에서도 seed 변동이 같다는 가정은 검증하지 않는다.
4. **A9′ LLM 호출 수를 다시 셌다.** 본 평가 문항은 210개다(어댑터 3 × 30 + 베이스 30 + 실제 기보 90). 합계는 990회, 약 1,000회다.
5. **9절 표의 머리글이 둘로 갈라져 있었다.** 4단계에서 행을 추가하다 생긴 것으로, 하나로 합쳤다.
